# ТЗ-03г. Интерфейс в стиле «Конфета» (вариант A)

Ветка `stage-03d` (от свежего `main`, после слияния этапа 3в). Объём ≈ 3–4 «дня Codex». Только интерфейс: механику,
числа, блоки и кирку не трогать.

**Владелец 10.11 выбрал стиль A** по макету Claude: `docs/design/mockups/ui-styles-2026-11-10.html` (открыть в
браузере; снимок рядом — `.png`, верхние два экрана). Макет — образец: пропорции, цвета, толщины и тени брать из его
CSS (класс `.A`; все размеры там в долях ширины экрана: `1cqw` = 1 % ширины). Остальные правила — `wiki/10-interfeys.md`
§1–2 (цвет кнопки = тип действия, размеры под палец, тайминги нажатия).

## 1. Стиль — точные значения

| Что | Значение |
|---|---|
| панель | фон `#FFF8EC`, обводка `#1E2140` толщиной 0,55 % ширины экрана, скругление 2,2 %, **твёрдая тень вниз** 0,7 % цвета `#1E2140` (без размытия) |
| строка внутри окна | фон `#F2E6D2`, та же обводка, без тени |
| текст | `#1E2140`; «станет лучше» — зелёный `#16A34A`; текст в мире — белый с обводкой `#1E2140` |
| купить за монеты | `#FFC83D` + монета + цена; нажата — сдвиг вниз на высоту тени, тень исчезает (60 мс), отпускание пружиной 140 мс |
| нельзя купить | `#B8BDC9`, цена красным `#B3202E` |
| закрыть | красный круг `#FF4D5E` с ✕, наполовину выступает за правый верхний угол окна |
| лента заголовка окна | цвет раздела («Улучшения» — фиолетовый `#A855F7`), белый текст, наклон −2°, выступает над верхним краем окна |
| ульта | круг, градиент `#A855F7` → `#EC4899`, обводка, светлое кольцо вокруг; заряд — заполнение по окружности; готова — пульс |
| полоска мира | дорожка `#E4D6BD`, заполнение — цвет мира |

Шрифт: один жирный округлый с кириллицей на всё (в макете Nunito Black). Подобрать среди шрифтов Roblox, проверить
кириллицу и цифры в Studio на трёх кандидатах, снимок в отчёт; выбрать ближайший к макету.

Реализация: модуль `Ui/Candy.luau` — панель, кнопка (5 типов из `wiki/10` §1), лента, значок-ячейка, полоска, монета с
числом, красная точка, окно (затемнение 45 %, закрытие ✕ / тап по фону / Esc). Обводка — `UIStroke`, скругление —
`UICorner`, твёрдая тень — вторая рамка под элементом (не `DropShadow`-картинка). Один `UIScale` по правилу `wiki/10` §1.
Все экраны собираются только из этого модуля; старые стили (`cream` этапа 3, `Kit` этапа 3б) удалить.

## 2. Экраны

1. **HUD** — как на макете: монеты слева сверху; плашка мира по центру (название, полоска, «до Плиты N», не шире 30 %);
   ⚙ и 👁 справа сверху; «Улучшения» слева снизу (фиолетовая, красная точка когда хватает на покупку); ульта справа
   снизу. Метка «Тест-режим» — маленькая, под ⚙.
2. **Улучшения** — окно на макете. Вкладки «Кирка» / «Карточки» — две ленты над окном (выбранная — цветная, другая —
   кремовая). Строка: ячейка-значок, название, «сейчас → станет», кнопка с ценой. Максимум — зелёная плашка «МАКС»
   вместо кнопки. Закрыто — замок и «с мира N». Карточки — крупные карты в ряд (значок, уровень, полоска до
   превращения с названием), под выбранной — ×1 · ×10 · Макс.
3. **Настройки, Creative, тосты, плашка нового мира, плашка превращения, подсказка «Стань сильнее»** — на том же наборе.
4. Числа над блоками: белые с тёмной обводкой, размер растёт с суммой (`wiki/10` §5.1).

## 3. Значки

Эмодзи из макета (⛏ ⚡ ⚙ ✊ ▦) — заглушки. Значки рисует Codex одним листом (генерация картинок, фон `#FF00FF`):
монета, кирка-со-стрелкой, молния ульты, шестерёнка, глаз, замок, кулак (Сила), стопка монет (Монеты), звезда-искра
(Крит), 6 форм «Размер удара», ширина стены, уровень кирки. Стиль: **наклейка** — простая форма, сочная заливка, тёмная
обводка `#1E2140`, белый блик, читается в 32×32; не пиксель-арт и не реализм. Лист — сначала в отчёт рядом с макетом,
потом загрузка.
