# ТЗ-03д. Блоки Claude в игре: все шесть граней, трещины, тоннель из блоков

Делается **в той же ветке `stage-03d`, после ТЗ-03г** (интерфейс), один PR на оба [владелец 10.11: «разом»].
Объём ≈ 2–3 «дня Codex». Причина: владелец оценил блоки этапа 3в в 1 из 10 — у блока текстура только на одной грани
(`WallRenderer.textureFace`: один `SurfaceGui`, `Face = faces[1]`), не видно границ блоков, земляная текстура, пола нет.

**Картинки блоков рисует Claude, Codex их не меняет и не рисует** (`AGENTS.md` п. 19). Источник:
`assets/blocks/manifest.json` (какая текстура у какой руды каждого мира) и `assets/blocks/upload/*.png`
(128×128, уже увеличены без сглаживания из 32×32). Генератор — `python3 assets/blocks/build.py`, обзор всех блоков —
`docs/design/mockups/blocks-final-2026-11-10.html`. **Все 10 миров готовы** [владелец 10.11: раскладки Б/Г/Д, мир 9 —
Подземное море, Магмовые ключи — финальный мир 10, старое «Ядро» убрано]. Если Claude что-то перерисует — файлы
**с теми же именами**, код при этом меняться не должен.

Что в манифесте (216 файлов): у каждого мира `rock` {`id`, `name`, `texture`, `variants`}, `lining`, `light`, `frame`
(`candy` или `hot` — у мира 10 рамка раскалена уже в картинке, коду делать ничего не надо), `env`, `layout` (для
справки) и `ores[]` {`id`, `name`, `rarity`, `texture`, `variants`, `glow`}. `variants` = {`golden`, `rainbow`,
`cosmic`} → имена текстур редких видов этого блока; шансы — `manifest.variants` (1/250, 1/10 000, 1/500 000, вики 18 §8).

## 1. Загрузка

Все PNG из `assets/blocks/upload/` — из папки, которую владелец разрешил для загрузки в Studio (этап 3в). ID —
в `assets/blocks/ids.json` (имя файла → `rbxassetid://…`) → `build-configs` → `Config.art.blocks`. Скрипт загрузки
должен уметь перезалить только изменившиеся файлы (сравнение по SHA-256, хранится в `ids.json`) — Claude будет
обновлять картинки. Тест: у каждой текстуры из `manifest.json` есть ID.

## 2. Текстура на всех шести гранях

1. Убрать `SurfaceGui`/`ImageLabel` с блоков шахты и старые текстуры «Каторги»-Roblox из шахты (кирка, замах, звук
   из 3в остаются).
2. Способ по умолчанию — **`MaterialVariant` на каждую текстуру** (`BaseMaterial = SmoothPlastic`, `StudsPerTile = 5` =
   размер блока), блок получает `MaterialVariant` своей руды: все грани текстурированы, одна отрисовка на материал.
   Проверить два риска и написать в отчёте результат:
   - **текстура ползёт**, когда стена едет к игроку (если материал привязан к миру, а не к детали) или рисунок
     сдвинут относительно граней блока. Тогда — объекты `Texture` (`StudsPerTileU/V = 5`) только на видимых гранях;
   - **размытость**: картинка 128 px на грань 5 studs не должна мылиться на расстоянии вытянутой руки. Мылится —
     написать, Claude отдаст 256 px.
3. `part.Color` — белый (иначе он перекрашивает текстуру); цвет руды уже в картинке.
4. Блок с `glow: true` (сокровища и драгоценная руда мира 10) — две-три белые искры раз в 1–2 с (`ParticleEmitter`, только в первых 25
   слоях), без `PointLight`.
6. **Редкие виды блоков** (вики 18 §8): если механика золотого/радужного/космического блока уже есть — такой блок
   получает текстуру из `variants` своего блока (камень другой, руда своя). Если механики ещё нет — только
   загрузить текстуры и положить их в конфиг (`Config.art.blocks`), саму механику не делать в этом этапе.
5. Граница между блоками видна за счёт рамки в самой текстуре; зазор между деталями убрать (детали ровно 5 studs,
   без z-fighting).

## 3. Трещины

`crack_1 … crack_4` (прозрачные PNG) — поверх **каждой видимой грани** блока, по которому бьют: `Decal` на этих
гранях, стадия = доля нанесённых ударов (≤ 8 ударов: 1 удар → ничего, затем 1…4 по долям 25/50/75/90 %). При
сквозном ударе — трещины на всех задетых блоках. Блок сломан — декали в пул, не создавать заново.

## 4. Тоннель из блоков

1. Пол, стены и потолок тоннеля — блоки той же сетки 5 studs, текстура `<порода мира>_lining` (темнее стены шахты).
   Пол — тоже блоки, под границей добычи и под площадкой.
2. Мир 1: деревянные крепи (`beam`) — две стойки и перекладина каждые 4 блока глубины, пол площадки — доски
   (`planks`). Образец вида — `assets/concepts/blocks/variant-1.jpg` и `render-W1` (Claude пришлёт).
3. Дальние сегменты (дальше `fx.depth.simpleFrom`) — те же блоки, но одной деталью на кусок стены (длинная деталь с
   той же текстурой, `StudsPerTile = 5` сохраняет сетку), чтобы держать бюджет.

## 5. Названия

Мир 1: порода **Галька** (`pebble`, было `dirt` «Земля»), обычная руда **Кремень** (`flint`, было `stone` «Камень»):
`scripts/balance/data.mjs` (имена), `scripts/design-decisions.json` (`ores`, `oreIds`), строки на 4 языках
(Pebble / Галька / Guijarro / Galet; Flint / Кремень / Sílex / Silex), `node scripts/balance/build-doc.mjs`, тесты.
Остальные миры: id и русские имена породы и руд — **ровно как в `assets/blocks/manifest.json`** (в `data.mjs`
Claude уже переименовал миры 9–10: 9 — «Подземное море», 10 — «Магмовые ключи»; «Ядро» как мир убрано, это цель за
последней Плитой). Строки на en/es/fr для новых имён перевести самому. В мире 1 у меди id `copper`, в мире 2 —
текстура `copper_w2` (руда та же).
