# ТЗ-01. Ядро бесконечной шахты (чистая логика, без Studio)

Ветка `stage-01` (от `main` после слияния этапа 0). Объём ≈ 2–3 «дня Codex». Всё в этом этапе — чистый Luau в
`src/shared/Mine/`, проверяется тестами в Lune. Ни одного Instance.

## Цель простыми словами

Сделать «мозг» шахты. Шахта — формула, а не склад кубов: что лежит в любом слое, вычисляется из номера слоя и зерна.
Хранятся только выбитые места. Мозг должен уметь: сломать блок, сломать форму, пробить вглубь на тысячи слоёв, честно
посчитать, сколько какой руды выбито (даже 75 000 блоков — мгновенно), сдвинуть стену по правилу «пока передний слой не
пуст — не едем», остановиться у Плиты-стража в конце мира, сохраниться в несколько килобайт и загрузиться обратно.

## 1. Координаты и константы

| Имя | Значение | Смысл |
|---|---|---|
| `x` | `-R … R`, центр 0, `R = (width-1)/2` | колонка; отсчёт от центра — при расширении 5 → 7 → 9 старые координаты не меняются |
| `y` | `0 … height-1`, 0 = пол | ряд |
| `d` | целое `0 … 2^31-1` | абсолютный номер слоя (глубина) |
| `lane` | `laneKey(x, y) = (x + 7) * 8 + y` | «дорожка» = все клетки с одинаковыми x, y вглубь |
| `MAX_W × MAX_H` | 15 × 7 | потолок формата (на запуске стена до 9×3 — это решает конфиг) |
| `CHUNK` | 50 | длина куска дорожки для квот руды; **все длины миров кратны 50** |
| `WINDOW` | 20 | сколько слоёв от фасада клиент знает; одиночные клетки можно ломать только в окне |
| `MAX_HOLES` | 4 000 | лимит отрезков пустоты на шахту |

Все константы — в `Config.mine` (п. 7), модули читают их оттуда; в коде только значения по умолчанию для тестов.

## 2. Модули

### 2.1 `Hash.luau`
- `Hash.u32(...)`: целочисленный хэш от до 6 целых аргументов (seed, x, y, c, salt …) на `bit32` (финализатор murmur3:
  `x ~= x >> 16; x *= 0x85ebca6b; x ~= x >> 13; x *= 0xc2b2ae35; x ~= x >> 16`, умножение по модулю 2^32 через
  `bit32` и разбиение на 16-битные половины — **без** потери точности double). Отрицательные x переводить в u32.
- `Hash.unit(...) -> [0, 1)` = `u32 / 2^32`.
- `Hash.noise(seed, x, y, d)` — гладкий value-noise по сетке с шагом 3 клетки (билинейная интерполяция по x, y и
  линейная по d) → `[0, 1)`. Нужен, чтобы редкая руда в соседних дорожках шла на близкой глубине (жилы).
- Тест: одинаковые входы → одинаковый выход; распределение `unit` на 100 000 значений — каждая десятая доля 10 % ± 0,5 %.

### 2.2 `Worlds.luau`
- Строит из `Config.worlds` массив `{ index, start, length, finish = start + length, plateDepth = finish - 1, ... }`.
- `Worlds.of(d) -> world` двоичным поиском. Глубже последнего мира — последний мир (бесконечный хвост) до будущих
  обновлений.
- `Worlds.durability(d)`: прочность обычного блока:
  `D_w × G_in ^ t`, где `t = (d - start) / length` ∈ [0, 1), `D_w` и `G_in` — из конфига мира. Плавно внутри мира,
  скачком на новом (п. 7). Прочность Плиты — п. 3.4.
- `Worlds.price(worldIndex, oreIndex)` — монет за блок.
- Проверка при загрузке: длины > 0 и кратны `CHUNK`, доли руды мира в сумме = 1 (±1e-9).

### 2.3 `MineGen.luau` — что лежит в клетке (квоты по кускам)
Точно как `06-tech.md` §1.4, с уточнениями:
- `quota(seed, x, y, c) -> { [oreIndex]: count }` — сумма = 50. Индекс 1 — «порода» мира (самая дешёвая руда мира, тоже
  приносит монеты — пустой породы для ребёнка нет). Порядок раздачи — от самой редкой к обычной; «богатство» куска
  `rich = 1 + richness * (2u - 1)` действует только на руды с индексом ≥ `rareFrom`; случайное округление `floor(e) + (u < frac)`.
- `cells(seed, x, y, c) -> { oreIndex }` (50 элементов): места ранжируются по `Hash.noise` по убыванию, самые «высокие»
  получают самую редкую руду. LRU-кэш на 256 кусков (ключ — `x, y, c`; кэш сбрасывается при смене seed).
- `specials(seed, x, y, c) -> { { d, kind } }`: 0–2 особые клетки куска; число — по `Config.worlds[w].specials.perChunk`
  (вероятность), место — `floor(unit * 50)`, тип — взвешенная таблица мира. На этом этапе один тип: `"chest"` (сундук-
  находка). Особая клетка заменяет руду в своей клетке (в `cells` и в квоте — вычесть).
- `cellAt(seed, x, y, d) -> (oreIndex, specialKind?)`.
- `rangeHist(seed, x, y, a, b, hist, finds)` — сколько какой руды в целых клетках `[a, b)` одной дорожки: полные куски — через
  `quota`, крайние — через `cells`; особые клетки → в `finds` (`{ x, y, d, kind }`), не в `hist`. `hist` ключуется
  `worldIndex * 64 + oreIndex` (кусок целиком лежит в одном мире — длины кратны 50).

### 2.4 `MineState.luau` — что выбито
Тип и инварианты — `06-tech.md` §1.3 (`top` + отсортированные отрезки `holes[lane] = {a1, b1, a2, b2, …}`). Плюс:
```lua
export type MineState = {
	v: number, seed: number, width: number, height: number,
	front: number,                    -- первый слой, где есть целый блок
	top: { [number]: number },        -- lane → всё в [front, top) пусто, top — первая, где МОЖЕТ быть целый
	holes: { [number]: { number } },  -- lane → [a, b) пусто, a > top, отсортировано, не соприкасаются
	holeCount: number,
	damage: { [number]: number },     -- cellKey → накопленный урон обычного блока (только окно; НЕ сохраняется)
	plateDamage: number,              -- урон текущей Плиты-стража (СОХРАНЯЕТСЯ) [владелец 09.11]
	collected: { [string]: boolean }?,-- не нужно: находка берётся один раз, потому что клетка удаляется один раз
}
```
API:
- `new(seed, width, height) -> MineState` (front = 0, все top = 0).
- `inWall(st, x, y)`, `isSolid(st, x, y, d)` (O(log k)), `isExposed(st, x, y, d)`: клетка целая и (`d == front` или
  у неё пустой сосед по ±x, ±y, `d-1`). Через пробитую дыру можно бить вглубь.
- `barrier(st) -> number`: глубина Плиты-стража мира, в котором стоит `front` (`Worlds.of(front).plateDepth`). **Ничто,
  кроме разрушения самой Плиты, не удаляет клетки на глубине ≥ barrier.**
- `removeCell(st, x, y, d, out) -> boolean` — только `d < front + WINDOW` и `d < barrier`; ложь, если уже пусто.
- `removeRange(st, x, y, a, b, out)` — «прогон»: `b` обрезается по `barrier`; уже пустые куски вычитаются; целые части
  добавляются в `out` (список `{x, y, a, b}` для подсчёта руды); слияние соседних отрезков; нормализация `top`.
- `removeLayers(st, a, b, out)` — то же для всех дорожек стены (ульта).
- `advance(st) -> delta`: `newFront = min(top)` по всем дорожкам; `delta = newFront - front`; `front = newFront`;
  при переходе через Плиту — `plateDamage = 0`. Урон обычных блоков из `damage` с `d < front` удалить.
- `widen(st, newWidth)` — только рост, нечётные ширины; новым дорожкам `top = front`. `height` не меняется на этом этапе.
- `compact(st, out)` — если `holeCount > MAX_HOLES`: пока больше — в дорожке с наибольшим числом отрезков **слить два
  ближайших соседних отрезка**, удалив целый промежуток между ними (его клетки → `out`, за них игрок получает награду).
  Дыры никогда не заполняются обратно.
- `check(st) -> (ok, err)` — все инварианты (`front = min(top)`, сортировка, `a > top`, нет соприкосновений, `holeCount`
  верен, ничего пустого на глубине ≥ barrier, кроме случая «Плита уже снесена» = front > plateDepth прошлого мира).

### 2.5 `Shapes.luau` — формы удара
`Shapes.cells(kind, x, y, width, height) -> { {x, y} }` в том же слое, обрезка по стене:
`single`; `pair` (клетка + над ней, у потолка — под ней) — стартовая кирка 2 «1×2»; `column3` (x, y-1..y+1, сдвиг внутрь
стены у пола/потолка) — «1×3»; `cross` (5); `square3` (3×3 с центром в клетке, сдвиг внутрь стены у края); `row`; `column`;
`wall` (весь слой). Применяются только к целым клеткам слоя `d` удара.

### 2.6 `Resolve.luau` — удар целиком (без фишек кирок — они в этапе 2+)
Вход: `st`, `pick = { strength: number, shape: string, ultLayers: number }`, `x, y, d`, `rng` (для будущих фишек).
Выход `HitResult`:
```lua
{ cells = { {x, y, d, gen} },  -- удалённые клетки в окне (gen = 0 удар; 1–3 — каскад, этап 2+)
  runs = { {x, y, a, b} },     -- удалённые прогоны глубже окна
  hist = { [key]: count },     -- руда по мирам
  finds = { {x, y, d, kind} },
  blocks = number,             -- всего логических блоков
  plateHit = number?,          -- урон, нанесённый Плите
  plateBroken = boolean }
```
Правила:
1. Клетка удара должна быть `isExposed`; иначе отказ.
2. **Прочность и сила** [решение 01]: `dur = Worlds.durability(d)`; `need = clamp(ceil(dur / strength), 1, 8)`;
   каждый удар добавляет `damage[cell] += 1`; блок ломается, когда `damage ≥ need` (значит не больше 8 ударов —
   слабый ребёнок не бьёт вечно). Форма удара ломает остальные клетки формы по тому же правилу (у каждой свой счётчик).
3. **Сквозной удар** [решение 01]: если `strength / dur ≥ 10` — каждая клетка формы ломается ещё и в следующем слое (2 слоя),
   `≥ 100` — 3 слоя, `≥ 1000` — 4. Через уже пустое — дальше по дорожке до нужного числа целых. Только `< barrier`.
4. **Ульта** `Resolve.ult(st, pick)`: `removeLayers(front, front + ultLayers)` с обрезкой по barrier. Если обрезка
   случилась (ульта упёрлась в Плиту) или `front == plateDepth` — Плита получает `plateHit = ultPlateHits × 3`
   ударов-эквивалентов (`Config.mine.plate`, «ульта прямо в плиту — ×3»).
5. **Плита-страж**: когда `front == plateDepth`, передний слой — Плита: одна на всю стену. Удар по любой клетке Плиты →
   `plateDamage += strength`; HP Плиты = `Config.worlds[w].plate.hp` (в единицах силы, см. п. 7). `plateDamage ≥ hp` →
   Плита снесена: удалить слой `plateDepth` во всех дорожках (единственное место, где можно «за barrier»),
   `plateBroken = true`, `plateDamage = 0`. Награда за Плиту — `Config.worlds[w].plate.reward` монет (п. 7).
6. После удара/ульты: `compact` при необходимости; `hist` и `finds` — через `MineGen.rangeHist` по всему, что попало в `out`.
7. `Resolve` **не** двигает стену — `advance` вызывает вызывающий код (сервис в этапе 2).

### 2.7 `Economy.luau` (минимум) — монеты за удар
`Economy.coinsFor(hist) = Σ count × Worlds.price(w, ore)`; множителей пока нет (этап 4–5). Возвращает double.

### 2.8 `MineCodec.luau` — сохранение
`encode(st) -> table` и `decode(t) -> (MineState?, err?)`, формат `06-tech.md` §1.7:
`{ v = 1, seed, w, h, front, plateDamage, top = base64(varint дельт от front по дорожкам в порядке laneKey),
holes = base64(для каждой дорожки: число отрезков, затем пары (зазор от предыдущего конца, длина) varint) }`.
`decode` вызывает `MineState.check`; битое → `nil, "причина"`. Свой base64 и varint в `src/shared/Mine/Bytes.luau`
(в Roblox есть `buffer` — используем его в обеих средах; в Lune `buffer` тоже есть).

## 4. Тесты (Lune) — `tests/mine/*.spec.luau`

Тесты используют **свой** конфиг-фикстуру `tests/fixtures/mine-config.json` (миры по 10 000 слоёв, чтобы пробивать на
5 000), а не боевой. Обязательные:
1. **rangeHist = перебор:** 10 000 случайных отрезков `[a, b)` (длины 1…400, в т. ч. через границы кусков и миров):
   сумма по `rangeHist` совпадает с перебором `cellAt` по каждой клетке, включая `finds`.
2. **Инварианты:** 100 000 случайных операций (`removeCell` в окне, `removeRange` вглубь до 5 000, `removeLayers`,
   `advance`, `widen`, каждые 1 000 — `encode → decode`) — после каждой `check(st)` = ок; сумма блоков из всех `out` =
   числу клеток, ставших пустыми (проверять по перебору на маленькой стене 3×2 и глубине ≤ 300).
3. **Правило движения:** дорожка (2, 1) пробита на 5 000 вглубь, остальные целые → `advance` = 0. Ломаем все клетки фасада,
   кроме одной → 0. Ломаем последнюю → 1.
4. **Проезд пустых:** слои 101–103 пусты во всех дорожках, руда на 104 → после очистки 100 `advance` возвращает `delta`,
   при котором `front = 104`, одним вызовом.
5. **Пустота сохраняется после езды:** дыра на 5 000 в одной дорожке, стена проехала 50 слоёв → дыра на месте
   (те же глубины), `isSolid` внутри дыры = false.
6. **Плита:** `removeRange` через `plateDepth` обрезается; ульта упирается — `plateHit` = 10 × 3; урон Плиты переживает
   `encode/decode`; Плита снесена → `front` уходит в следующий мир, `plateDamage = 0`.
7. **Удары и сила:** при `dur/strength = 20` нужно 8 ударов (потолок), при 2,5 — 3; сквозной удар 2/3/4 слоя на порогах
   10/100/1 000 ×.
8. **Сохранение:** `encode → decode` = исходное состояние (кроме `damage`); 50 видов порчи (обрезанный base64, `a > b`,
   пересечения, `front ≠ min(top)`, отрицательные, лишние байты) → `decode` возвращает `nil, err`; размер `encode` у шахты
   с 4 000 отрезков ≤ 20 КБ (вывести фактический).
9. **Лимит дыр:** 5 000 мелких дыр → после `compact` `holeCount ≤ 4 000`, клетки только удалились (никогда не
   появились), их руда попала в `out`.
10. **Скорость** (печатать в отчёт, проверка — порог): ульта 5 000 слоёв × 15 дорожек (`removeLayers` + `rangeHist`) — < 5 мс;
    25 000 × 45 — < 50 мс; 10 000 обычных ударов — < 200 мс. Замер `os.clock`, медиана из 5 прогонов.
11. **Детерминизм:** одинаковое зерно → одинаковая руда в 1 000 случайных клеток; разное зерно → другая.
12. **Шапы:** каждая форма у углов и краёв стены 5×3, 7×3, 9×3 не выходит за стену и даёт нужное число клеток.

## Чего НЕ делать

Сеть, Studio, рендер, кирки с фишками, молния, карточки, множители — следующие этапы. Не писать «на будущее» API,
которого не просит ТЗ. Не использовать `math.random` в `src/shared/Mine` (только `Hash` и переданный `rng`).
