# ТЗ-Б6. Существо — данными, как в Blender: дешевле при той же детализации

Исполнитель — Codex. Ветка `bosses-art`, PR не сливать. Делается **после боссов Б5б и до новых существ Б4**
(боссы рисует код «Каторги», им это не нужно).

## 0. Слова владельца [19.11]

«Блендер не так много лимитов кушает, а вы — да. Найди связь, чтобы сэкономить, может, надо улучшить инструмент».

## 1. Почему Blender дешевле (Claude, по коду обоих конвейеров)

| | Blender, «Каторга»-Roblox (`blender-block-mob`) | Наши картины |
|---|---|---|
| Что пишет агент на одно существо | **данные** 150–320 строк (`PARTS`, `JOINTS`, `actions()`) поверх общего `blockmob.py` (637 строк) | **код** 1 377–1 557 строк TS (исполин, король Б5: кожа, позы, ключи, регалии, оружие, пол) + карточка 361 |
| Образец облика | один лист в 4 вида | 9–13 листов поз на существо |
| Проверка облика | `compare`: тот же вид, тот же масштаб, рядом и 50/50 (`cmp.cjs`) — числа, мало попыток | критик словами, до 3 попыток на лист |
| Объём | 5–8 клипов | 23–33 клипа, 8 сторон, сцена 72 фазы, автомат |

Главное — первые две строки: у нас каждое существо пишется кодом с нуля, а детализация (шерсть, мех, цепь, корона,
мох) каждый раз рисуется заново. Объём мы не режем — владельцу нужен набор и детализация исполина.

## 2. Что сделать

1. **Формат существа — данные.** `c/<id>.creature.json` (или `.ts` только с данными): части (примитив, размеры,
   материал, сустав-родитель), суставы, материалы, наборы деталей (п. 2), позы ключами, клипы (тайминг, ключи,
   события), пресеты эффектов. Общий сборщик строит риг `f15-rig` и рендерит. Старые существа не переписывать:
   `snap all --check` — без изменений.
2. **Наборы деталей** — общие генераторы, из которых детализация исполина получается десятком строк: шерсть
   клочьями, мех-воротник, ткань с складками и каймой (плащ, мантия, шинель), цепь, корона, пластины с заклёпками,
   чешуя, перья, мох и трава, трещины со светом, бахрома и эполеты, листья. Параметры: где, сколько, размер,
   палитра, запаздывание. Цель: новое существо ≤ 350 строк данных и ≥ 400 примитивов.
3. **`npm run ws -- compare <id> <ref.png> [--anim idle --frame 0]`** — наш рендер в виде и масштабе образца:
   рядом, 50/50, силуэт IoU, расстояние палитры, одна строка с итогом. Первый проход критика по облику — по этим
   числам; словами — только то, что числа не ловят.
4. **Образец облика — один лист в 4 вида** (спереди, сбоку, сзади, 3/4), как в Blender; листы поз — только для
   своих приёмов и трюка, остальное — библиотека движений.
5. **Проверка на деле.** Лунный страж (каталог §9.10 п. 37) — первым на новом формате: замер строк данных,
   примитивов, времени, генераций. Владелец сверяет процент лимита с исполином (15 %) и пингвином (3–4 %).
