## 1. Что не так (разбор Claude по файлам PR)

1. **Не ходят.** `walk` шагает на месте (у `bramble_warden` левый край тела во всех 24 кадрах ходьбы — x = 52), в
   картине существо стоит в одной точке. Это ошибка ТЗ-Б1, а не исполнения: так было написано.
2. **Мало подробностей.** Числа §7.1в, кадр 0 `idle`, тело 1:1:

   | | Пикселей | Цветов | Плотность краёв | Самое большое пятно |
   |---|---:|---:|---:|---:|
   | крупный дракон-питомец «Каторги» | 4 819 | 59 | 0,90 | 3,4 % |
   | Квакунья | 5 325 | 34 | 0,71 | 9,3 % |
   | Титан Жерло | 7 351 | 18 | 0,55 | 6,9 % |
   | Монетный дракон | 6 302 | 25 | 0,74 | 4,7 % |

   Крупные существа получили больше пикселей, но не больше подробностей: гладкие грани, мало тонов, нет фактуры
   материалов. Тела по 200–500 строк против 1 500–2 500 у боссов «Каторги». Сравни глазом: `assets/detail-bar.png`
   в скилле.
3. **Существо мелкое в картине** (35–55 % высоты поля), **фоны одинаковые** — шесть из семи легли одной мостовой.
4. **Критик пропустил**: в `lineup.gif` Страж и Кукловод вдвое мельче наших, сравнение льстило.
5. **375 МБ кадров и GIF в git.** Рендер детерминирован — их место в Release, а не в истории игры.

## 2. Задача — те же семь существ, те же семь команд

Каждая команда (§3.2) по своему существу:

1. **Карточка**: сценарий `life` на 12–16 с по секундам с маршрутом по полу (§8.7) и список подробностей по §4.0б
   (≥ 25 / 35 / 50 по редкости). Критик принимает до кода.
2. **Тело**: холст по новой таблице §2.3 (96 / 128 / 160), тело на переднем плане — 55–65 % высоты поля.
   Проход «Подробности» (§4.0б): фактура каждого материала, 5–7 тонов с переходами шахматкой, все мелочи из списка.
   Числа §7.1в — зелёные (тест в `tools/creatures/test/`, порог по редкости).
3. **Ходьба по-настоящему**: `walk_<dir>` в 8 направлениях с перемещением, стопы стоят на полу (тест скольжения в
   координатах поля), разгон и остановка с весом, развороты через стороны рига. Шёлковый дракон летает.
4. **`life`** — главная анимация картины (§8.7): гуляет, разворачивается, подходит к зрителю, уходит вглубь, заходит
   за предметы переднего плана, делает 1–2 приёма в разных местах. Петля без шва.
5. **Фон** по §8.3: свой материал пола темы, ≥ 6 вариантов плитки, три плана с `bgf`, свой свет темы.
6. **Приёмы** остаются, но пересобираются на новом теле; эффекты ложатся на новые полы.
7. **Критик** по §7.2: в одном масштабе с крупным питомцем и боссом «Каторги», оценки 1–5, круги до ≥ 4,5 по всем
   пунктам. Общий Критик партии — §7.2б, `paintings.gif` в `life`.

Сводящий до команд: новые холсты и поле, слой `bgf`, движение по полю в рендере, `walk_<dir>` в `meta.json`
(скорость, точка ног), тесты скольжения в координатах поля и числа §7.1в, исправленная линейка сравнения
(эталон и наши — одинаково ×3). Плюс git по §2.5: `assets/creatures/*/gif/` и `frames/` убрать из дерева и в
`.gitignore`, полный набор — архивом в GitHub Release `creatures-pilot-2`. PR потом сливается **сжатием в один
коммит** (squash), тогда 375 МБ из истории ветки в `main` не попадут.
