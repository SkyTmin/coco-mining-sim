# ТЗ-04в — трещины и прочность блока как в Майнкрафте

Владелец 11.11: «надо просто сделать как в майне анимацию: если удерживаешь, блок копается и трещины переключаются; как
только перестал копать, анимация исчезает, то есть прочность блока восстанавливается». Сейчас урон по клетке (`st.damage`)
копится навсегда, и стена покрывается недобитыми клетками с трещинами. Делать **в ветке `stage-04`** (PR #12).

## 1. Правило

- Пока игрок копает (держит кнопку / палец / автокопание идёт), урон по клеткам копится как сейчас, трещины растут по
  стадиям (`Config.art.cracks`, 10 стадий, `BlockBreak.stage`).
- Игрок **перестал копать** → весь недобитый урон по клеткам сбрасывается: и по клетке под прицелом, и по соседям, задетым
  Силой / Трещинами / перками / ультой. Трещины исчезают, у блоков снова полная прочность.
- Смена цели во время копания урон **не** сбрасывает [решение: иначе карточки, бьющие по соседям, теряют смысл; в
  Майнкрафте сброс и при смене блока — если владелец захочет так же, это одна строка, см. §2].
- Плита (`st.plateDamage`, барьер мира) **не** восстанавливается [решение: это «босс» стены с полосой HP, её бьют долго;
  ждёт подтверждения владельца].

## 2. Сервер (владелец исхода — сервер)

- В сессии шахты (`MineService` session) хранить `lastHitAt` — время последнего принятого удара (`HitService.onIntent`,
  после `Validate.take`, для обычного удара и для `Ability`).
- Сброс: если `os.clock() - lastHitAt > pick.interval + DIG_GRACE`, где `DIG_GRACE = 0.3 с` [решение], — очистить
  `st.damage` (все ключи), отправить окно клиенту (`MineService.window`). Проверять в общем Heartbeat-цикле сервиса раз в
  ~0,1 с, только для сессий с непустым `st.damage` (никакой работы для стоящих игроков).
- Явный интент `DigStop` (новый `op` в `Wire.encodeIntent`, без аргументов, rate-limit как у `Resync` — 0,5 с) сбрасывает
  сразу, не дожидаясь таймера. Клиент шлёт его при отпускании кнопки/пальца и при выходе из режима копания.
- Опция для владельца: константа `RESET_ON_RETARGET = false`; при `true` смена целевой клетки сбрасывает урон всех
  остальных клеток.
- Урон больше не должен попадать в сохранение: при сохранении профиля/состояния шахты `st.damage` пишется пустым
  (валидатор в `MineState` уже принимает пустую таблицу). Старые сохранения с уроном при загрузке очищать.
- Ульта «до дна»/«слоями» и перки: их урон по недобитым клеткам сбрасывается тем же правилом, после окончания действия
  (пока ульта идёт, `lastHitAt` обновляется её тиками).

## 3. Клиент

- `Mine/Controller.luau`: при отпускании (мышь, тач, геймпад, выход из первого лица) — сразу убрать трещины локально
  (предсказание, `BlockBreak.cracks` с пустым уроном) и отправить `DigStop`. Пришедшее окно сервера — истина.
- Трещина на блоке под прицелом всегда видна, пока его копают (как сейчас); правило `NO_CRACK_LEFT` для соседей остаётся.
- Никаких новых всплывающих сообщений.

## 4. Проверки (Lune)

- Урон копится при ударах чаще `interval + grace`; одна пауза длиннее — `st.damage` пуст, окно отправлено.
- `DigStop` чистит сразу; повторный `DigStop` чаще 0,5 с игнорируется.
- Плита после паузы сохраняет урон.
- Сохранение после копания содержит пустой `damage`; загрузка старого сохранения с уроном его очищает.
- Сосед, задетый Силой, теряет урон вместе с основной клеткой.

## 5. Приёмка (Claude проверяет в Studio через релей)

1. Зажал на блоке — трещины идут по стадиям; отпустил на середине — трещины пропали сразу; зажал снова — копка с нуля.
2. Копаю широкой кистью (Сила 25+) — соседние трещины видны, пока держу; отпустил — пропали все.
3. Автокопание без отпускания — урон не сбрасывается между ударами при любом уровне скорости кирки.
4. Плита: отпустил — полоса HP плиты не восстановилась.
5. Выход из игры с недобитыми блоками и вход — стена чистая.
6. `stylua --check src tests`, `rojo build`, `lune run tests` — зелёные; отчёт с коммитом и скриншотами 1–2.
