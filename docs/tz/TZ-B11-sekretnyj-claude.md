# ТЗ-Б11. Второй секретный Claude — Звездохвост, лис-комета

Владелец 19.11 (Мурлен принят, Феникс Codex — нет): «сделай ещё одного секретного, но очень динамичного, быстрого,
красивого и детализированного, главное логика и без артефактов… анимации не должны быть стандартны от слова вообще, они
могут идти дальше, могут всё что угодно». Пример нестыковки у Мурлена: достаёт из цилиндра предметы, а дырки цилиндра не
видно — таких мелочей быть не должно. Идею хомяка-шахтёра владелец отклонил («не нравится идея с шахтой сейчас»), выбрал
лиса-комету.

Делает Claude сам, кодом на риге f15, без генераций. Ветка `secret-claude` (от `bosses-art`, общая механика трюков —
версия Codex `65e6e2dc`). Тело — семейство `light-quadruped` (как у Снежного лиса), своя внешность.

## 1. Существо

**Звездохвост** `comet_fox`: небольшой лис цвета ночного неба — тёмно-синяя спина в звёздных крапинах, светлая грудка,
рыжие «огоньки» на ушах и лапах, три хвоста из света (в первом облике), колокольчик-звезда на ленте. Во втором облике
(«Комета») хвостов девять, шерсть загорается, за ним остаётся след.

Сцена своя: «Звёздная поляна» — вершина холма ночью: Млечный Путь, далёкие холмы и озеро с отражением звёзд, каменный
круг, светящиеся цветы, светлячки (живут 2–3 мелочи).

## 2. Трюки, облик, выходы

| Клип | Что | За стандарт |
| --- | --- | --- |
| `trick` «Тройной рывок» | присед, вилянье — три рывка зигзагом по картине (рывок 2–3 кадра, приземление с заносом 6–8), за ним копии-тени; тени догоняют и сливаются с ним во вспышке | скорость, перемещение через всю картину |
| `trick_b` «Огненное кольцо» | крутится, хвосты складываются в огненный обруч в воздухе; прыжок сквозь обруч (обруч делится на переднюю и заднюю половины), обруч сжимается в звезду, лис ловит её пастью и подкидывает — звезда лопается искрами | реквизит из собственных хвостов |
| `phase` «Девять хвостов» | хвосты делятся по одному 3 → 9 с хлопками, огонь бежит волной от хвоста к голове, глаза загораются, вспышка | событие, не смена цвета |
| `trick-f2` «Комета по раме» | лис превращается в комету и проносится по всей раме картины, углы рамы вспыхивают, возвращается с заносом | весь круг поверх рамы (`over`) |
| `trick_b-f2` «Звездопад» | прыжок вверх за верхнюю кромку картины, пауза без лиса, по небу сцены падают звёзды, лис падает метеором в центр — ударное кольцо, поза | выход за раму, сцена отвечает |
| `show` | по небу сцены летит падающая звезда, падает в картину, свет в воронке, из света поднимается лис, стряхивает искры, поза (держит 0,7 с) | появление из неба сцены |
| `peek` | сначала над нижней кромкой появляются уши, потом глаза, лапы ложатся на раму, хвост перекидывается через раму | слой `over` |

## 3. Планка и правила

- Высота 55–65 % поля (у четвероногого — по самому длинному размеру 80–90 % холста), `minPrimitives` ≥ 900, ≥ 30
  мелких деталей, ≥ 7 запаздывающих частей (хвосты, уши, лента, колокольчик, шерсть на груди, щёки).
- Динамика: быстрые движения 2–4 кадра, задержки 6–10; замах → действие → перелёт → успокоение; сплющивание и
  растяжение, следы скорости.
- Логика: каждый предмет откуда-то берётся и куда-то девается; к концу клипа ничего не висит; всё, что окружает тело,
  делится на переднюю и заднюю половины; у открытых предметов видна полость.
- Без артефактов: перед сдачей — каждый 2-й кадр каждого трюка, `phase` и `show` на ×1; найденные и исправленные
  артефакты — в отчёте с номерами кадров.
- Проверки: `npm test`, `gate comet_fox`, `snap all --check`.
