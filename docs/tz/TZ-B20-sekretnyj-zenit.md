## 1. Почему не копия

Покемоны — чужие охраняемые персонажи. Берём дух легендарок: стихийный дракон-божество, пара «день — ночь», приёмы,
эволюция-пробуждение. Не берём: не оранжевый дракон с огнём на хвосте, не белый дракон с турбиной, не чёрный дракон с
генератором, не солнечный лев и не лунная летучая мышь, не призматический чёрный кристалл. Корни своего — мифы, где
дракон или зверь глотает солнце и так бывает затмение (китайские, индийские, северные сказки — общая мифология), и
слово «зенит». Имя, облик, реквизит, сцена и сюжеты свои. Палитра первого облика медно-янтарная, второго — индиго с
серебром (не белый и не чёрный дракон).

Кто он одной строкой: **двуногий дракон цвета закатной меди — костяная корона из лучей, крылья как витраж заката,
солнечная жемчужина в груди, хвост с лезвием-полумесяцем; когда он глотает солнце, наступает затмение**.

Карточка для галереи: «Говорят, Зенит спит на солнечных часах выше облаков и просыпается с последним лучом. Он носит
солнце в груди, а когда ему становится тесно, проглатывает его — и посреди дня высыпают звёзды».

## 3. Сцена «Солнечная обсерватория» `sun_observatory`

Закат над облаками. Цикл 3 с.

- **Небо**: вверху глубокий синий, к горизонту янтарь и роза; тонкие перистые облака подсвечены снизу; огромное
  низкое солнце справа, наполовину в облаках, приглушённое (не ярче существа); редкие птицы далеко.
- **Даль**: море облаков внизу — розовые верхушки, фиолетовые тени, медленно плывут; заснеженные пики силуэтами.
- **Площадка**: круглые **солнечные часы** из бледного камня во весь пол — бронзовые часовые линии лучами от центра,
  у каждой — свой знак-час; слева сзади высокий бронзовый **гномон**-клинок, его длинная тень лежит на циферблате;
  справа сзади на постаменте бронзовая **армиллярная сфера** (кольца медленно поворачиваются за цикл); по краю —
  каменный парапет с прорезями.
- **Передний план** (`front`): обломки парапета по углам, бронзовая чаша-жаровня с тлеющими углями слева, лепестки.
- Сцена тёплая, но приглушённая; существо выделяется светом жемчужины, кромками чешуи и перепонками на просвет.

## 4. Рама «Рама обсерватории» `frames/eclipse_drake.ts`

Бронза с зелёной патиной: рейки — шкала градусов (частые насечки, каждые десять — длиннее), по шкале раз за цикл
пробегает солнечный блик; углы — маленькие армиллярные кольца; сверху — медальон-солнце с лунным диском на краю;
снизу — бронзовая пластина солнечных часов с крошечным гномоном.

## 5. Язык эффектов

| Эффект | Как выглядит |
| --- | --- |
| свет солнца | тёплые искры-пылинки тянутся от солнца сцены в перепонки крыльев, перепонки разгораются от кромки к кости |
| луч | белое ядро, золото, оранжевый край, дрожь жара вокруг; в точке касания — брызги расплава |
| расплав | борозда оранжево-белая → красная → тёмное стекло с бликами, остывает к концу клипа |
| комета | огненный хвост спиралью, искры, тепловая вспышка картины ≤ 0,2 |
| зеркала | кристаллические осколки-линзы с бронзовой оправой поднимаются из часовых знаков, луч между ними, на конце — золотая пыль |
| затмение | лунный диск наползает на солнце, тень бежит по сцене слева направо, звёзды, корона вспыхивает кольцом |
| переворот чешуи | граница волной бежит от груди к лапам, хвосту и крыльям: на границе искры, за ней — новый цвет |
| корона | серебряно-белые ленты пламени с фиолетовой кромкой, плетью; следы — серебряные дуги на камне, остывают |
| тень | чёрная лужа с серебряной кромкой, кольца ряби; брызги тьмы — капли с серебряным бликом |
| звёзды | четырёхлучевые серебряные искры; упав, стоят на камне кристалликами и гаснут по одной |

Логика предметов: свет берётся у солнца сцены → луч → борозда расплава остывает в стекло; взлёт с кольцом пыли → силуэт на
фоне солнца → комета над рамой → посадка с кольцом расплава; зеркала поднимаются из часовых знаков → луч по кругу →
вспышка → золотая пыль осыпается, знаки тлеют и гаснут; корона берётся из чёрного солнца → плети → дуги на камне;
нырок в тень → тень бежит по полу → выныривает у стекла → капли тьмы стекают по стеклу; звёзды падают из короны →
шар → звездопад → кристаллики на камне гаснут, последняя звезда разбивается о стекло.

### 6.1 Бытовые

| Клип | Что происходит |
| --- | --- |
| `idle` | дышит грудью, жемчужина пульсирует, корона чуть колышется, кончик крыла подрагивает, хвост с полумесяцем покачивается |
| `walk` | шаг хищного ящера: голова ровно, шея пружинит, хвост уравновешивает, сложенные крылья покачиваются |
| `look` | прикрывает глаза крылом от солнца, смотрит вдаль, поворачивает голову, ноздри, крыло обратно |
