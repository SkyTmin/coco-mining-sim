# ТЗ-03ж. Рассыпание блоков «как в Telegram» и ульта-волна

Ветка `stage-03g` от свежего `main` (PR #10 слит). Объём ≈ 2–3 «дня Codex».
«Эффект Таноса» из ТЗ-03е §10 владельцу не понравился [владелец 11.11]: кубики 2,5 studs слишком крупные. Его **убрать
целиком**: кубики-призраки, их пул, ветер, пыльную бурю, золотую обводку. Поза «щелчок», вспышка и счётчик денег
остаются.

**Образец — демо Claude, утверждено владельцем:** `docs/design/mockups/dust-demo-2026-11-11.html` (открыть в браузере,
в обоих списках выбрать «4×4»). Повторить **в точности**, с одной разницей: блоки у нас 3D, а демо 2D.
Все числа ниже взяты из кода демо.

## 1. Данные пылинок (рисует Claude, готово)

`assets/blocks/grains.json` (генератор `assets/blocks/grains.py`, его вызывает `build.py`):
- у каждой текстуры шахты (порода и руда, её виды `alts`, редкие `variants`) есть сетка **8×8 пылинок**: средний цвет
  каждой клетки 4×4 пикселя (`grainPx: 4`);
- `cells` — 64 шестнадцатеричные цифры, строка за строкой от левого верхнего угла грани;
- каждая цифра — номер цвета в палитре `palettes[palette]` (16 цветов): `w1…w10` для обычных блоков мира,
  `golden`, `rainbow`, `cosmic` для редких видов.

Подключить через `build-configs` → `Config.art.grains`. Тест: у каждой текстуры блока шахты есть запись.

Палитры фиксированные, потому что цвет `ParticleEmitter` нельзя менять, пока его частицы в воздухе: смена `Color`
перекрашивает и уже вылетевшие. Поэтому делаем **один эмиттер на каждый цвет палитры**: 16 × (10 миров + 3 редких вида)
= 208 эмиттеров. Цвет каждому задаётся один раз. Эмиттер на своём `Attachment` в одной папке.

## 2. Пылинка (общие настройки эмиттера)

Пиксель текстуры = 5/32 stud = 0,156 stud. Пылинка 4×4 пикселя = **0,625 stud**.

| Свойство | Значение (из демо) |
|---|---|
| Texture | `fx_dust` (квадрат) |
| Size | 0,625 до 45 % жизни, затем **сразу** 0,3125 (в демо пылинка «мельчает вдвое») |
| Transparency | 0 до 55 % жизни, затем линейно до 1 |
| Lifetime | 0,50–0,87 с |
| Начальный разлёт | случайное направление (сфера), скорость 1,4–2,8 stud/с |
| Дальше | скорость плавно стремится к **(0, +4,06, 0) stud/с** (вверх) с постоянной 2,5 1/с: `v += (цель − v) · 2,5 · dt` |
| Rotation / RotSpeed | 0 / 0 (пиксели не крутятся) |
| Orientation | FacingCamera |
| LightInfluence | 0 (цвет точно как в текстуре) |
| LightEmission | 0 |
| Squash | 0 |

Штатными `Acceleration` и `Drag` закон из таблицы получается так: `Acceleration = (0, 10,15, 0)`,
`Drag = 2,5 / ln 2 ≈ 3,61`. Если `Drag` в Roblox считается иначе, подобрать так, чтобы совпало с законом.
**Проверить замером:** положение пылинки через 0,2, 0,4 и 0,6 с совпадает с формулой с точностью 10 %. Результат —
в отчёт.

## 3. Разлом блока

1. В момент разлома блок **сразу скрывается** (в пул). Вместо него — пылинки с **каждой видимой грани**: грань открыта
   воздуху и смотрит в сторону камеры (`dot(нормаль, к камере) > 0`), не больше 3 граней.
2. На грани сетка 8×8. Центр пылинки (i, j) — центр клетки 0,625×0,625 на поверхности грани, сдвинутый наружу на
   0,02 stud. Цвет — `cells` текстуры этого блока (того вида `alts` / `variants`, что стоял в клетке). Эмиттер — номер
   цвета в палитре. Для каждой пылинки: `Attachment.WorldPosition = центр`, затем `Emit(1)`.
3. **Порядок выпуска — от точки удара во все стороны**, без направления «слева направо» [владелец]. Задержка пылинки:
   `0,14 с × (0,65 · min(1, расстояние_до_точки_удара / 3,75 stud) + 0,35 · шум(клетка))`. Шум — плавный, значения
   0..1, своя функция. Точка удара — куда попал луч прицела. При сквозном ударе у следующих блоков точка удара — центр
   их передней грани.
4. Пылинки, которым ещё рано, ждут в очереди и выпускаются в своём кадре. Весь блок укладывается в 0,14 с.
5. «Меньше движения»: 16 пылинок по 1,25 stud (сетка 4×4), без разлёта, только подъём.

## 4. Ульта — волна в глубину [владелец 11.11]

Начало как в демо: передняя грань рассыпается **от центра к краям**. Дальше та же волна идёт **вглубь шахты**:
- центральная полоса ломается быстрее всех;
- соседние кольца отстают;
- самые крайние отстают сильнее всего.

Фронт получается клином: остриё в центре впереди, края сзади. Слои накладываются друг на друга, и видно бегущую волну.

**Время разлома клетки** (x — полоса, y — ряд, d — слоёв от старого фронта):

```
t(x, y, d) = 0,25 + LAG · r(x, y) + d / V
r(x, y) = √((x − центр_x)² + (y − центр_y)²)   — в блоках, от центра сечения шахты
LAG = 0,14 с на блок                           — у стены 7×3 крайние отстают на ≈ 0,44 с, как в демо
V = D / (Tульты − 0,25 − LAG · r_max)           — слоёв в секунду, длительность ульты не меняется
```

0,25 с — пауза после щелчка: поза и вспышка остаются из ТЗ-03е. `D` — на сколько слоёв продвинулась ульта.
В разлом идут только клетки, которые ульта действительно ломает; пустоты остаются пустыми.

Каждая клетка в свой момент `t` рассыпается как в §3. Точка удара — центр её передней грани. Внутри блока порядок
от центра грани наружу, за 0,14 с.

**Камера** едет за **самым медленным** кольцом: `глубина_камеры(t) = max(0, (t − 0,25 − LAG · r_max) · V) − 2 слоя`.
Весь клин впереди виден. Езда кончается, когда крайнее кольцо дошло до `D`.

**Детализация** (иначе телефон не потянет: за секунду ломаются тысячи блоков):
- пылинки получают только блоки ближе **10 слоёв** (50 studs) к камере в момент разлома;
- дальние блоки исчезают без частиц: уменьшение 1 → 0 за 0,12 с, из пула;
- лимиты: не больше **400** `Emit` за кадр и **4 000** пылинок в воздухе;
- при превышении блок получает 16 пылинок по 1,25 stud вместо 64, а при двойном превышении исчезает без частиц;
- в отчёте замер: ≥ 30 FPS на эмуляторе iPhone 7 от начала ульты до конца.

## 5. Баг после ульты [владелец]

После ульты, когда блоки «летят к игроку», они возвращаются: один ряд появляется **за линией, где стоит игрок**, потом
исчезает.
1. Воспроизвести, найти причину (вероятно, кусок окна стены перерисовывается до того, как пришло новое состояние),
   исправить.
2. Проба в Studio: каждый кадр 2 с после конца ульты пишется список видимых блоков с глубиной. Ни один блок с глубиной
   меньше нового фронта не появляется ни в одном кадре. Пусть так 10 ульт подряд на разной глубине. Результат —
   в отчёт.
