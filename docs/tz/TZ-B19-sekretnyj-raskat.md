## 1. Почему не копия

Покемоны (Nintendo / Game Freak / The Pokémon Company) — чужие охраняемые персонажи. Берём дух легендарок: стихийный
зверь-божество, величие, эволюция-пробуждение, «приёмы». Не берём ни одного конкретного: не жёлтая мышь, не тигр-пёс
с облаком на спине, не чёрный дракон, не кот-боец с жёлтыми когтями. Корни своего — японский бог грома Райдзин с кольцом
барабанов за спиной (общая мифология), громовой зверь райдзю из сказок, русское «раскат грома». Имя, облик, реквизит,
сцена и сюжеты свои.

Кто он одной строкой: **поджарый двуногий громовой зверь — кристаллические рога-громоотводы, грива из живой грозовой
тучи, светящиеся жилы-молнии, медные наручи и кольцо боевых барабанов за спиной; каждый удар в барабан — молния**.

Карточка для галереи: «Говорят, он спит в грозовой туче над самой высокой вершиной. Когда Раскат бьёт в свои восемь
барабанов, над горами катится гром, а молнии сами ищут его рога. Пробудившись, он становится бурей».

## 3. Сцена «Пик громовержца» `thunder_peak`

Ночь, буря, вершина. Цикл 3 с.

- **Небо**: многослойные тёмные тучи сине-фиолетовые, в центре сверху медленный вихрь-«глаз бури» с тусклым светом;
  за цикл две далёкие молнии в разных местах (ветвистые, 2–3 кадра, подсвечивают тучи); косой дождь по всей картине.
- **Даль**: море облаков внизу, подсвеченное молниями; зубчатые пики-силуэты, тёмные с синим ободом.
- **Арена**: плоская вершина из древних каменных плит, по кругу — кольцо высеченных рун, слабо светится бирюзой;
  трещины между плитами; по бокам два разбитых менгира с медными громоотводами, на остриях раз за цикл искра; за ареной
  — обломок древних ворот.
- **Передний план** (`front`): зубчатые камни по углам, лужи с отражениями и кругами от дождя, щебень.
- Тёмный фон, существо выделяется свечением жил, глаз и рогов.

## 4. Рама «Рама громовержца» `frames/storm_lord.ts`

Чёрный базальт с медью: рейки — шершавый камень с фасками, по средней линии медная инкрустация-зигзаг, по ней бежит
волна бирюзового света; высеченные знаки бури между зигзагами; медные угловые накладки с заклёпками; на верхней рейке
медный громоотвод со стеклянным шаром — раз за цикл в нём искра; на нижней — медный боевой барабан со скрещёнными
палочками.

## 5. Язык эффектов

| Эффект | Как выглядит |
| --- | --- |
| молния | ломаная с ветками: белое ядро, бирюзово-голубое свечение, фиолетовый край; 2–3 кадра, затем послесвечение и `flash` картины |
| рывок | зигзаг-след света по пути, 3 силуэта-послеобраза тают за 6 кадров, искры там, где оттолкнулся |
| удар в барабан | вспышка кожи, ударное кольцо в перспективе, дуги звука, во втором облике вспышка в туче |
| подпалина и трещины | тёмные следы с тлеющей бирюзой по краю, остывают к концу клипа |
| парящие камни | обломки плит поднимаются кольцом (передние перед телом, задние за ним), дрожат от статики |
| дождь и ветер | косые штрихи, брызги, изогнутые штрихи ветра |
| пробуждение | белый силуэт тела пульсирует между малым и большим всё чаще, затем взрыв-кольцо и разряды |

Логика предметов: молния ударила в лапу → копьё из молнии → вбито в землю → трещины → камни поднялись → раздавлены в
пыль; когти по стеклу → полосы тают; рывки → подпалины по пути → остывают; барабаны раскрываются из сложенного кольца и
складываются обратно; шаровая молния → взрыв поверх рамы → разряды по раме гаснут; удар с неба → кратер → свет в
трещинах остывает.

## 6. Клипы и раскадровка (кадры при 24 к/с)

Бытовые: `idle` 3 с цикл, `walk` 1 с цикл (крадущийся шаг хищника), `look` 1,5 с, `fidget_a` 2,5 с, `fidget_b` 2,5 с,
`happy` 2 с, `sleep_in` 1,5 с, `sleep` 3 с цикл, `sleep_out` 1,5 с, `wake_startled` 1,2 с, `hatch` 3 с; второй облик:
`idle-f2` 2 с цикл, `happy-f2` 2 с; `phase` 5 с; трюки 11–12 с; `show` 7 с; `peek` 2,5 с.

### 6.1 Бытовые

| Клип | Что происходит |
| --- | --- |
| `idle` | дышит грудью, грива-туча медленно клубится, по жилам пробегает свет, барабаны кружат и тлеют, хвост покачивается |
| `walk` | крадущийся шаг хищника: голова низко и ровно, плечи ходят, хвост уравновешивает, облака гривы отстают |
| `look` | вскидывает голову к вихрю, уши поворачиваются, ноздри, рога вспыхивают, обратно |
| `fidget_a` «Разряд» | хрустит шеей, разминает лапу — искра бежит от плеча к когтям, между когтями дуга, сжимает кулак — щелчок, гаснет |
| `fidget_b` «Отряхивается» | стряхивает дождь всем телом, брызги и искры летят, грива распушается и опадает |
| `happy` | сальто назад со следом молнии, приземление на три точки, искры |
| `sleep_in` / `sleep` / `sleep_out` | ложится, сворачивается, как большой кот, хвост на морду; во сне грива дышит, по жилам изредка искра; просыпается, потягивается, рога загораются |
| `wake_startled` | прыжком в боевую стойку, рога вспыхивают, шерсть дыбом, разряд по кольцу барабанов |
| `hatch` | каменное яйцо с жилами света; трещины-молнии бегут по скорлупе, коготь пробивает её, взрыв осколков, он выпрямляется в облаке пыли, отряхивается, осколки тают |
| `peek` | из-за края рамы сначала два горящих глаза в тени, потом рога, оскал-ухмылка, уходит |

### 6.4 Второй облик

`idle-f2` (2 с, цикл): парит, кольцо барабанов поворачивается на 45° за цикл (восемь одинаковых — бесшовно), грива-туча

**`trick-f2` «Ураган»** 12 с (288 кадров): раскручивает кольцо, вокруг закручивается смерч (задняя стенка за ним,
передняя перед ним), поднимает обломки и дождь; ведёт смерч по арене вглубь и обратно; бросает его в зрителя — дождь и
обломки бьют в стекло (`over`), смерч рассыпается кольцом ветра; обломки падают, капли стекают; стойка.

**`trick_b-f2` «Шаровая молния»** 11,5 с (276 кадров): сводит лапы — между ними растёт плазменный шар; проводит его

по рейкам рамы и гаснут; стойка.

**`trick_c-f2` «Удар с неба»** 12 с (288 кадров): взмывает вверх и уходит за верх картины; тишина, вихрь в небе
