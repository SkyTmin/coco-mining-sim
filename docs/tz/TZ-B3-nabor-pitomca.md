«Этот результат оставляем и переходим к следующему. Хочу, чтобы не все анимации были ударами: сделаем анимации как
у питомцев — ожидание, ходьба, радость, удар, сон и так далее. Например, когда тыкнешь по картине — радость. Те, что

Восемь готовых картин **не трогаем** (переделка позже). Б3 — стандарт набора, инструменты и одно новое существо на
нём; владелец смотрит, потом партия.

## 1. Стандартный набор (у каждого существа, любой редкости)

Основа — питомцы «Каторги» (`docs/design/wiki/20-pitomcy-i-bossy.md` §2: покой, ходьба, радость, трюк, атака, сон).

| Клип | Длина | Петля | Что | Когда играет в игре |
|---|---|---|---|---|
| `idle` | 3–4 с | да | дыхание, моргание, перенос веса | по умолчанию |
| `fidget_a`, `fidget_b` | 1,5–3 с | нет | свои жесты характера: осмотреться, почесаться, зевнуть, отряхнуться | изредка из покоя |
| `walk_<dir>` | 1 с | да | 8 направлений (уже в библиотеке) | бродит по полу картины |
| `look` | 1,5 с | нет | поворачивается к зрителю, смотрит | изредка; когда игрок подошёл |
| `happy` | 1,5–2,5 с | нет | **радость**: сжатие → подскок или вскинутые руки → верх радости (глаза дугой) → приземление; эффект радости своим языком (искры, сердечки, ноты, конфетти своего материала) | **тап по картине**, редкая находка |
| `trick` | 2–3 с | нет | **трюк** — игра, не удар: жонглирует, ловит муху, крутится, балансирует предметом | лайк / двойной тап |
| `attack` (`tech_*`) | как сейчас | нет | приёмы, число по редкости — без изменений (§5 стиля) | изредка; навык готов |
| `sleep_in` | 1–1,5 с | нет | зевок → ложится, глаза закрываются | хозяин стоит без дела |
| `sleep` | 3–4 с | да | спит: бока ходят, «Z» своим языком | |
| `sleep_out` | 1–1,5 с | нет | потягивается, просыпается | хозяин вернулся |
| `wake_startled` | 0,8–1,2 с | нет | тап во сне: вздрагивает, подпрыгивает, оглядывается → дальше `happy` | тап, когда спит |
| `hatch`, `turn`, `tired` | как сейчас | | | |

Правило стыков: **каждый разовый клип начинается и кончается позой покоя на своём месте**, так игра переключает
клипы без рывка. У каждого клипа — кадры, где его можно прервать (`interrupt` в `meta.json`), не реже раза в 0,3 с:
тап должен отзываться сразу.

## 2. Поведение картины — данными, а не одной петлёй

`assets/creatures/<id>/behavior.json` (схема в `tools/creatures/bodies/` или рядом с карточкой, проверка в `gate`):
- состояния и веса: доля времени на прогулку, покой с жестами, `look`, `trick`, `attack`; удар — **иногда** (≈ один
  за 30–45 с), прогулка 35–50 % времени;
- точки остановок на полу (уже есть в карточках как `beats.at`) — прогулка между ними по `walk_<dir>`;
- события: `tap` → `happy` (во сне — `wake_startled` → `happy`), `like` → `trick`, `idle_owner` → `sleep_in` →
  `sleep`, `owner_back` → `sleep_out`, `skill_ready` → `attack`;
- `life` и `paintings.gif` теперь **собираются этим же автоматом** с фиксированным зерном (30 с), а не пишутся руками.

## 3. Каждая анимация — от референса (§4.3в стиля, §10 промтов)

Для **каждого** клипа набора (не только ударов): аналог из жизни → 2–3 подсмотренных примера из интернета (игры,
мультфильмы, видео животных и людей; ссылки и что взято — в карточку; рисуем и пишем сами) → свой лист ключевых поз
по шаблону §10.2 → самопроверка §10.4 → `ws sheet-lint` → позы по листу → `ws ref`. Промт каждого листа сохраняется.
Для радости, трюка и сна логика та же, что для удара: откуда движение берёт силу, где тело сжимается и растягивается,
куда смотрит морда, откуда появляется эффект (из тела, а не из воздуха).

## 4. Инструменты

1. `npm run ws -- export-ref <id> [anim] [кадр]` — только тело существа (слои `body` + `lit`), ×4 ближайшим
   соседом, на `#FF00FF`, в `.studio/` — образец облика для генерации (§10.1 п. 2).
2. `npm run ws -- sheet-lint <png> --grid CxR [--air 3,4] [--ref <png>]` — машинная проверка листа по §10.6;
   код выхода 1 при ошибке. Тесты: лист с лишним пятном, с персонажем у края, с разным ростом, с каймой — ловятся.
3. `npm run ws -- label <png> --grid CxR --roles "…;…"` — подписи ролей под клетками (модель текст не пишет).
4. `gate`: у существа есть все клипы набора; разовые клипы начинаются и кончаются позой покоя (маска силуэта
   первого и последнего кадра против `idle` кадра 0 — IoU ≥ 0,9); у каждого клипа есть лист и `ws ref` проходит.
5. **Просмотрщик** `tools/creatures/viewer/`: одна HTML-страница без сборки — стена картин, автомат из
   `behavior.json` крутится живьём; **тап по картине → радость**, двойной тап → трюк, кнопка «уйти» → через 5 с сон,
   тап по спящему → вздрогнул и обрадовался. Кадры — атласы PNG: фон и рама один раз, существо слоями отдельно;
   до 15 МБ на существо, каждый файл до 16 МБ. Работает на телефоне (касание, без наведения мыши). Claude
   опубликует его владельцу ссылкой.

## 5. Существо Б3

**Луговой исполин** (`meadow_colossus`, необычный, каталог §9.1 п. 2): черепаха с холмом на панцире — трава,
валуны, кривое деревце; лапы-колонны, древняя голова. Тип тела — тяжёлый четвероногий из библиотеки (свой шаг:
медленный, тяжёлый). Приёмы — 2 по редкости (каталог: встаёт на задние лапы и обрушивает передние; второй — свой, по
площади или на расстоянии, по §2.4).

Идеи набора (подсмотри, проверь логикой, можно лучше): радость — топает передними лапами по очереди, деревце
трясётся, с него сыплются листья и распускаются цветы; трюк — подкидывает валун с холма носом и ловит панцирем; сон —
голова и лапы уходят в панцирь, деревце никнет, светлячок садится на ветку; `wake_startled` — голова выскакивает,
листья осыпаются.
