# Эталонные боссы «Каторги»

Эти листы сняты в Chromium из исходных рисовальщиков боссов на локальном стенде. У каждого ряда свой режим, под кадрами указано время от его начала. Кадры рассчитаны при 24 к/с. В строку отобраны до десяти кадров, включая первую засечку на моменте удара, пуска или смены состояния (красная рамка). Поле показывает локальную позу и, для отмеченных строк, локальную метку или эффект. Траектории по арене и перемещения героя остаются за пределами этих кадров. [SkyTmin/coco-instruments, 523bae1](https://github.com/SkyTmin/coco-instruments/tree/523bae1)

Две прозрачные последовательности покоя для общей картины содержат по 72 кадра с шагом 1/24 с и фиксированной опорой. Порядок чтения по строкам слева направо. Ширина и высота одной ячейки, число колонок и опора записаны в JSON.
