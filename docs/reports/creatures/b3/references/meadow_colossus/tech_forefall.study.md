# tech_forefall

Аналог из жизни. Тяжёлое животное привстаёт на задних ногах и ловит свой вес двумя передними.

У Мейбриджа виден нижний край фазы: одна передняя нога почти выпрямлена и несёт нагрузку, другая сгибается. Заимствовал момент перехода веса обратно вперёд. [Фотография](https://commons.wikimedia.org/wiki/File:Horses_rearing%2C_etc.%2C_some_with_rider_%28rbm-QP301M8-1887-652b~1%29.jpg)

На пляже задние копыта остаются внизу, в то время как передние конечности обе сгибаются наверху. Перенёс само вращение грудной клетки относительно задней опоры. [Фотография](https://commons.wikimedia.org/wiki/File:Rearing_horse_Chennai.jpg)
