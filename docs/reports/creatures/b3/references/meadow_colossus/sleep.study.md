# Тихий сон

В расслабленном положении шея и мягкие ткани у входа в панцирь лежат между ногами; малая перемена объёма позволяет показать дыхание.

- Нос расположен низко между передними ступнями. У спящего исполина оставляем под ободом видимый край головы. [Фотография «Galapagos Tortoise»](https://commons.wikimedia.org/wiki/File:Galapagos_Tortoise.jpg).

- Расслабленный панцирь расположен низко, передняя лапа с согнутым локтем выставлена из-под края. На этом строим низкую спящую позу. [Фотография «Chelonoidis-niger-donfaustoi-wallow»](https://commons.wikimedia.org/wiki/File:Chelonoidis-niger-donfaustoi-wallow.jpg).

- Круглые плечи примыкают к мягкому горлу с боков. Для дыхания изменяется этот узкий промежуток. [Фотография «Closeup of a Tortoise (11075911475)»](https://commons.wikimedia.org/wiki/File:Closeup_of_a_Tortoise_(11075911475).jpg).

Неглубокий вдох расправляет бок у передней ноги → выдох возвращает складку; веки закрыты в обеих фазах. Мерцание у ветки синхронизируется с выдохом.
