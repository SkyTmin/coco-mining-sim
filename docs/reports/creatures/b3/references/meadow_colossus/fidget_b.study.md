# Пробует траву

Пасущаяся черепаха опускает клюв под переднюю кромку панциря, прихватывает траву, чуть поднимает голову и закрывает челюсть.

- Спереди видны зелёные стебли у клюва, голова лишь немного выступает между передними ногами. Ставим этот момент сразу после захвата. [Фотография «Galápagos tortoise»](https://commons.wikimedia.org/wiki/File:Gal%C3%A1pagos_tortoise.jpg).

- Крупный план показывает раздельные кромки клюва и тёмную щель между ними; глаз при этом обращён к пище. Отсюда небольшой ход жующей челюсти. [Фотография «Salad Time - Flickr - Andrea Westmoreland»](https://commons.wikimedia.org/wiki/File:Salad_Time_-_Flickr_-_Andrea_Westmoreland.jpg).

- В нижней точке вытянутая шея держит подбородок между двумя подошвами, панцирь остаётся выше. Это предел наклона. [Фотография «Galapagos Tortoise»](https://commons.wikimedia.org/wiki/File:Galapagos_Tortoise.jpg).

Из стойки опускает голову перед ближайшей лапой → щиплет воображаемую травинку у самого пола → поднимает морду и смыкает клюв → стойка.
