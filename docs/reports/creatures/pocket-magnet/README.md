# Полюсик

Обычный питомец с бирюзовой шёрсткой и подковообразным магнитом на кончике хвоста. Место действия — солнечный стол игрушечного мастера. [Открыть картину](https://skytmin.github.io/coco-mining-sim/?pet=pocket_magnet)

| Рисунок до анимации | Что перенесено в картину |
| --- | --- |
| [Вид спереди и сбоку](references/pocket_magnet/model.webp) | Кремовый ромб и мордочка, мятный воротничок, медные веснушки, две полоски на бедре и коралловая подковка с серебряными торцами. |
| [Рыбка](references/pocket_magnet/fish.webp) | Полюсик опускает полюс к стальному ушку. Сначала рыбка опирается хвостом на лоток, потом повисает вертикально. При возвращении бортик удерживает игрушку, пока магнит отходит в сторону. |
| [Звезда](references/pocket_magnet/star.webp) | Шнур закреплён на крючке. Полюсик отступает, увлекая звезду за собой, отпускает её, приседает и ловит на обратном пути. После ловли ещё немного уступает её движению и доводит до покоя. |
| [Повседневные позы](references/pocket_magnet/life.webp) | Начало шага, прыжок, короткая лапа у щеки, поворот к магниту и сон. |
| [Мастерская](references/pocket_magnet/room.webp) | Из отдельного рисунка без героя сделан фон 160 × 128. Кронштейн, шнур, звезда, лоток и рыбка добавлены на игровых слоях. |

Для всех листов использован один рисунок внешности. В каждом кадре раскадровки заранее заданы положение камеры, опора героя и положение игрушки. Тексты пяти промптов лежат рядом с рисунками.
