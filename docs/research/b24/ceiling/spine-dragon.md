# Dragon · сменные рисунки для взмаха

В клипе flying верх плеера показывает силуэт с поднятой веерообразной перепонкой, затем крыло прижимается к боку, и его зубчатая кромка перемещается ниже спины. Морда и хвост остаются различимыми в обеих позах. Откройте flying в верхнем плеере и прокрутите один взмах. [Кадры автора](https://esotericsoftware.com/spine-examples-dragon)

| Что известно | Что из этого следует для пробы | Уверенность |
| --- | --- | --- |
| Экспорт 4.2.22 хранит у right-wing последовательность с count=9, для обоих крыльев есть отдельные дорожки sequence. На отметке 0,8 с интервал смены изображения задан 0,0333 с, в начале 0,0667 с. На этой же анимации есть костные дорожки. В старом пояснении девять рисунков названы отдельными вложениями. Для структуры файла ориентир — JSON версии плеера. [Первоисточник](https://esotericsoftware.com/files/examples/4.2/dragon/export/dragon-ess.json) | Для одной пробы оставить основное тело на его дорожках и проверить сменные силуэты только у части, которая выворачивается. Сравнить граничные позы крыла на ×1 и число промежуточных рисунков, нужных для понятного взмаха. | Высокая для файла и различия силуэтов. Указанные интервалы относятся к переключению крыльев, частота экрана из них неизвестна. |
