# Mark Ferrari и Ian Gilman · Living Worlds

У разработчика открываются кадры оригинального календаря и его мобильного восстановления. Сопоставь низкий боковой свет и дневное освещение одного ландшафта в разделе *The Way It Was*.

| Что известно | Что из этого следует для сравнения | Уверенность |
| --- | --- | --- |
| У пикселя хранится индекс. Ferrari подготовил ряд палитр для времени суток. Свет меняет сторону при тех же индексах базового рисунка. Это описал программист оригинала Gilman. | Для шкалы «мир» важнее увидеть направление света на разных поверхностях, чем просто заметить смену общего оттенка. | Высокая в устройстве. Критерий восприятия — наша гипотеза. |
| У дождя, снега и дыма могли быть собственные накладки с циклическими палитрами. Ferrari объясняет, что разные длины и скорости диапазонов убирают синхронный пульс. | Для сравнения нужны две шкалы времени: движение фактуры за секунды и смена освещения за часы. При скорости реального времени короткий GIF показывает только первую. Вторую можно проверить таймлапсом. | Высокая для принципа. Состав накладок конкретного месяца требует проверки. |

**Предел доказательства.** Размер современной сборки и расход заряда не измерялись. Цикл палитры меняет цвет только у заранее размеченных пикселей. Следующий опыт должен проверить движение границы тени по собственному рисунку.
