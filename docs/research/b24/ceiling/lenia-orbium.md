# Lenia · движущееся пятно сохраняет внутренний рисунок

В плоской версии Orbium bicaudatus на синем поле видны красная сердцевина и два узких боковых выступа. Сопоставлены кадры 0 и 25, при счёте от нуля. Во втором пятно смещено вправо и вверх, просветы по обе стороны ядра различимы в обеих фазах. [Плоская анимация](https://raw.githubusercontent.com/Chakazul/Lenia/adfc542939266de7f4bb7ebb552e8499701ee107/R/orbium.gif)

| Что известно | Что следует проверить в нашей мастерской | Уверенность |
| --- | --- | --- |
| В R-примере задано начальное поле чисел и радиус ядра. На шаге берутся преобразования Фурье поля и ядра, вычисляется взвешенное окружение и функция изменения. Новое значение клетки ограничивается диапазоном от нуля до единицы. [Начальное поле и обновление](https://github.com/Chakazul/Lenia/blob/adfc542939266de7f4bb7ebb552e8499701ee107/R/Lenia.Rmd#L94-L158) | Проверить, может ли в собственной пробе движущееся пятно иметь устойчивые внутренние детали без отдельного клипа для каждой детали. | Высокая для этого кода. Исход не переносится автоматически на другую начальную форму. |
| Код сохраняет 50 шагов под именем orbium.gif. Проверка через Pillow дала 50 кадров. Псевдоцвет передаёт значения поля. [Начальное поле и обновление](https://github.com/Chakazul/Lenia/blob/adfc542939266de7f4bb7ebb552e8499701ee107/R/Lenia.Rmd#L94-L158) · [Отображение значений](https://github.com/Chakazul/Lenia/blob/adfc542939266de7f4bb7ebb552e8499701ee107/R/Lenia.Rmd#L52-L68) | Смотреть центр и пустоты одновременно. Одно смещение центра ещё не отличает меняющуюся форму от перемещения готового спрайта. | Высокая для длины файла и способа построения. Визуальное отличие требует сравнения последовательностей. |

Для сверки можно извлечь два кадра командой ImageMagick: `magick orbium.gif -coalesce -delete 1-24,26-49 +append /tmp/orbium.png`. На 3D-иллюстрацию из Screencap этот разбор не опирается.
