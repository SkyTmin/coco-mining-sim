# Valenberg · Night moves

В начальном кадре мост открыт, на кадре 16 справа входит поезд, к 24-му его окна заполняют мост. Провода и фигуры снизу остаются ориентирами при смене средней части кадра. [Выставочная копия Night moves](https://www.espaciobyte.org/exp/117/hd/05.gif)

Названия слоёв рабочего файла неизвестны. |

Цифры относятся к выставочной копии. Чтобы повторить, декодируйте все кадры через Pillow `Image.open`, `seek`, `convert("RGB")`. Для указанной области возьмите `crop((left,top,right,bottom))`, посчитайте разные массивы байтов и сложите значения `duration` в миллисекундах. Правая и нижняя границы в `crop` исключаются. Цикл, в котором есть проезд, ещё не подтверждает внешнего расписания поездов.
