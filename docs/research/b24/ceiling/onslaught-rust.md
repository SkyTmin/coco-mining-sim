# Onslaught · Rust, портрет в шляпе

На кадре, который выложил разработчик Elder0010, лицо и край шляпы пересекают горизонтальные цветовые полосы, очки лежат поверх поля шляпы. [Кадр автора](https://content.pouet.net/files/screenshots/00062/00062225.png) · [Запись демо, на которую ссылается художник](https://www.youtube.com/watch?v=KoDyNpPrdb8)

| Что известно и где проверить | Что отсюда следует для сравнения | Уверенность |
| --- | --- | --- |
| Художник CONS описывает работу над портретом: взял серый, красный, чёрный и коричневый из предшествующего перехода, начал с фигуры, затем нарисовал фон. На показе планировали обратный порядок появления: сначала фон, поверх него девушка. [CONS, запись Rust](https://homeofcons.wordpress.com/2013/12/13/rust/) | При сравнении переходов проверить, какие цвета связывают соседние сцены и отделяется ли фигура при появлении. Порядок рисования и показа можно выбирать независимо. | Высокая для слов автора. Во времени отдельные фазы по этому PNG не определяются. |
| В том же разборе автор отбрасывает два задумывавшихся скроллера. В другом эпизоде многокадровый лист сменился более простыми пузырями: автор сообщает, что не смог получить нужный вид в маленьком многоцветном спрайте. [CONS, запись Rust](https://homeofcons.wordpress.com/2013/12/13/rust/) | При оценке прототипа сохранять отклонённый вариант в журнале, а при сравнении с потолком учитывать лишь вышедший эффект. | Высокая для отчёта участника о решениях команды. |

Визуально проверен кадр портрета. Задумку перспективной прокрутки нельзя считать свойством готовой сцены.
