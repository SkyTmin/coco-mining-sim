# Б24 В4 · рисованный портрет с одним защитным жестом

Дождь сбивает огонёк. Птица наклоняется и укрывает его широким крылом. Огонь восстанавливается и продолжает гореть, когда дождь стихает. Это короткая проба до выбора владельца. Взята форма 10 из каталога Claude. Большую часть времени сохраняются поза для портрета и узнаваемый профиль. На несколько секунд изменение среды заставляет героя нарушить эту позу. [Эпизод](out/paper-portrait.gif) · [Восемь фаз](out/paper-portrait-sheet.png) · [Сравнение при ×1](compare.html) · [Формы Claude](../../../b26/forms.md) · [Логика](../../../b26/world-logic.md)

На листе слева направо, сверху вниз — кадры 0, 50, 55, 64, 74, 87, 115, 193. Нумерация от нуля, 16 кадров/с. Капля с листа летит к светильнику, огонь слабеет, птица вздрагивает. После приседа она переносит вес вперёд и раскрывает веер. С его крайнего пера стекают капли. На земле остаётся лужица. Камера, две опоры ног, длины клюва и маховых перьев принадлежат одной сцене. Проекция веера меняется при раскрытии. Огонь расположен отдельно от границы крыла. Биологический вид и художественные имена у этой пробы не назначены.

## Как проверить причинность

Опорное правило одно: пока крыло перекрывает струю над огнём, фитиль может разгореться. После крупной капли огню нужно время для восстановления. Беспокойство показано глазом и резким отводом головы, усилие — приседом, переносом веса и раскрытием ближнего крыла. График дождя и позы повторяются при каждом запуске. Состояние пламени интегрируется на каждом шаге, а его высота и подсветка используют одно значение. На седьмой секунде оно равно 1,00. При том же дожде и времени с выключенным укрытием остаётся 0,07. Это сравнение двух значений внутри программы, отдельный зрительский опыт с двумя роликами не проводился. [Функции wingEdge, pose и flameHistory](render.mjs)

В первой версии растеризатор показал чёрный диск вместо ореола. Независимый зритель заметил вырез вокруг огня. После замены градиента композицией полупрозрачных слоёв тот же зритель увидел единое пространство, пересказал защиту от дождя и отметил, что по одному листу неясно, восстановилось бы пламя само. В заключительном рендере проверка укрытия использует координаты кончика крыла и отдельно вычисляется контроль без него. Две версии смотрел один агент. Слепой просмотр конечного листа и оценка владельца учитываются отдельно.

## Воспроизведение и цена

Из корня репозитория с зависимостями `tools/creatures`:

```sh
node docs/research/b24/probes/paper-portrait/render.mjs
(cd tools/creatures && node --import tsx ../../docs/research/b24/render-comparisons.mjs ../../docs/research/b24)
```

Откройте `compare.html`. Чужие кадры подгружаются по ссылкам из атласа. Первый скрипт создаёт только собственные GIF и PNG в `out/`. Каждая поза построена векторными контурами и формами, никаких внешних изображений для отрисовки не требуется. В декодированном GIF 200 кадров 384 × 320, сумма задержек 12 500 мс. Просмотр однократный: после завершения видно последствие.

Для одной такой сцены подготовлены исходный портрет со связанными головой, крылом, ногами и хвостом, две схемы силуэта крыла, движение крупной капли, материал огня, освещение, след воды и 8 фаз контроля. В инструменте понадобятся независимые позы частей, крепления, маска укрытия, состояние предмета и просмотр соседних кадров. Это затраты конкретной пробы. Стоимость следующей картины в часах или токенах без второго автора и журнала работы не измерена.

В облаке один запуск через Node занял 5,16 с, максимальная резидентная память процесса по `resource.getrusage(RUSAGE_CHILDREN)` — 529 048 КиБ. Это цена офлайн-рендера. GIF занимает 5 915 983 байта, PNG-лист — 408 971. Декодированный RGBA-кадр занимает 491 520 байт. Одновременное хранение всех 200 кадров в таком виде потребовало бы 93,75 МиБ. Проигрыватель может хранить только часть кадров, измерений на реальном телефоне нет. Для сотен карточек важен замер декодирования и расхода памяти при пролистывании.
