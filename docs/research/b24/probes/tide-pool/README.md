# В4. Жизнь с последствиями и вводом зрителя

Рабочее обозначение пробы — береговой водоём. 16 секунд, одно придуманное существо с широкой клешнёй, один камень и три яйца. [Интерактивная проба](probe.html) · [Сравнение в одном экранном размере](compare.html)

**Что показать владельцу.** Откройте пробу, коснитесь воды, пока герой только идёт к камню. Затем начните сначала и коснитесь после того, как он затолкнёт камень в русло. Можно просто смотреть — на двенадцатой секунде приходит естественная волна. Раннее касание вызывает волну до преграды, позднее — после. Цена действия для героя видна во времени, пока он толкает тяжёлый предмет. Эффект состоит в изменившейся сцене и следующем движении героя.

## Постановка

У героя здесь одна забота — сохранить кладку сухой. Он отходит от яиц к камню, подставляет клешню, медленно сдвигает его. Волна течёт по руслу слева. В момент встречи с камнем она либо проходит, либо останавливается. После прорыва остаются мокрая полоса и новая позиция кладки. Герой подходит к сместившимся яйцам. При защищённой кладке он остаётся у преграды. В исходном коде физика хранит решение отдельно для каждой волны, а смещение кладки и протяжённость мокрого песка сохраняет до явного перезапуска. Собственный рисунок и все движения построены командами Canvas 2D. Чужих спрайтов или повторно окрашенных принятых картин в сцене нет. [Ввод, состояние, постановка](probe.html)

Форма взята из каталога Claude, № 2 с откликом из № 13. Зритель влияет на событие среды, оно получает два видимых исхода. Смысл жеста проверяется по последовательности «причина, действие, след». В этой постановке нет требования, чтобы зритель нажимал точно вовремя, и пустой прогон имеет свой исход. [Формы Claude](../../../b26/forms.md) · [Правила мира](../../../b26/world-logic.md) · [Порядок замысла](../../../b26/intent.md)

## Сравнение

На сравнительной доске одинаковые поля 264 × 188 CSS-пикселей. Для сопоставления открываются оба проигрывания, Полюсик и три авторских кадра. У Полюсика рыбка висит над пустым лотком на кадре 79, а при следующем обычном действии вновь лежит в нём. В пробе оставленный след определяет место следующего действия существа. В Rain World разработчик описывает самостоятельные действия животных, в Eastward художник объясняет программное движение среды и отдельно рисованные изменения, в Spiritfarer состояние пассажира связывает заботу с последующим ответом. Это ориентиры поведения и кадрирования. ## Воспроизведение

В облаке нужны Chromium, Python с Pillow и Playwright для экспорта. Сама проба открывается из одного HTML, её просмотр не требует установки. Команды из корня репозитория снимают два ответа и готовят рядом кадр принятой картины. Здесь каталог вывода локальный и предназначен для просмотра. Внешние три кадра на доске остаются по адресам их авторов.

```sh
probe_dir=docs/research/b24/probes/tide-pool
python "$probe_dir/render.py"
repo_dir=$(pwd)
(cd tools/creatures && node --import tsx "$repo_dir/docs/research/b24/render-comparisons.mjs" "$repo_dir/$probe_dir/out")
python -m http.server 3100 --bind 127.0.0.1 --directory "$probe_dir"
```

Открыть `http://127.0.0.1:3100/probe.html` или `/compare.html`. Из двух автоматически полученных GIF и листов PNG выбирать запись по исходному такту касания, из `out/captures.json` — конечные координаты и замер для этой машины. Вывод о поколении и выборе направления делает владелец после просмотра всех проб.
