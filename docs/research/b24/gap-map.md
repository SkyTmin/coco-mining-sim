# Б24 В2. Где зритель увидит разницу

**Сильнее всего могут измениться две вещи.** Последствие поступка может пережить короткий трюк и повлиять на следующее действие героя. Один движущийся источник света может одновременно изменить вид нескольких поверхностей в комнате и на самом герое. Это первые две гипотезы для В3 и В4. Ранг означает порядок опытов. Владелец ещё не выбирал поколение, а слепой зритель ещё не сравнивал пробы. [Решения](../DECISIONS.md) · [Доска из девяти сравнений](gap-board.html)

За исходную точку взяты принятые `astral_seer` и `pocket_magnet` на базе со слитым Б22. Астрал уже показывает событие → след в мире → восстановление. У Полюсика маленькая металлическая рыбка имеет видимый вес и опору. Имитировать это увеличением числа вспышек или клипов означало бы повторить достигнутый результат. [Трюк Астрала](../../../tools/creatures/c/astral_seer-fx.ts#L107) · [Опора и движение рыбки](../../../tools/creatures/c/pocket_magnet-poses.ts#L98) · [Протокол слепого просмотра Полюсика](../../PROGRESS.md)

## Как смотреть

Собственные кадры получены из штатного `compose` в нормальном варианте, сторона 0, при 24 кадрах/с. На доске по каждой оси рядом стоят Астрал, Полюсик и авторский кадр внешнего примера. Все три поля по 224 × 192 экранных пикселя, без обрезки и растяжения. Широкие игровые сцены оставляют поля сверху и снизу. Масштаб фигуры внутри композиции остаётся авторским. Для оценки тонкого края нажмите на исходник. Ссылки на технические разборы есть в карточках потолка. [Доска](gap-board.html) · [Рендер и номера кадров](render-comparisons.mjs)

Из корня репозитория в облачном окружении с установленными зависимостями мастерской:

```sh
repo_dir=$(pwd)
output_dir=$(mktemp -d)
cp docs/research/b24/gap-board.html "$output_dir/"
(cd tools/creatures && node --import tsx "$repo_dir/docs/research/b24/render-comparisons.mjs" "$output_dir")
python -m http.server 3100 --bind 127.0.0.1 --directory "$output_dir"
```

Открыть `http://127.0.0.1:3100/gap-board.html` в том же окружении. В папке будут исходные PNG, лист фаз, лист соседних кадров и манифест с SHA-256 по RGBA. Ссылки справа ведут к изображениям авторов, для них нужен интернет. Два отдельных рендера дали одинаковые файлы. При проверке в Chromium загрузились 29 из 29 изображений, все 27 ячеек сравнений имели указанный размер. На экране шириной 360 пикселей прокручивается строка, ширина документа осталась 360.

## Проверка вариативности

Два прогона по 1 440 отсчётов (60 секунд), без ввода. Сравнивали тройки «клип, позиция, номер кадра», а не пиксели или мнения зрителя. Для двух отдельных 30-секундных окон одного прогона знаменатель равен 720. Команда ниже запускается из корня репозитория.

| Картина | Клипы в атласе | Кадры первого/второго обычного трюка | Повтор с тем же seed, расхождения | Seed + 1 | Два окна с начальным seed |
| --- | ---: | ---: | ---: | ---: | ---: |
| Астрал | 32 | 132 / 120 | 0 / 1 440 | 594 / 1 440 | 645 / 720 |
| Полюсик | 26 | 166 / 178 | 0 / 1 440 | 1 042 / 1 440 | 693 / 720 |

```sh
node --input-type=module <<'JS'
import { readFileSync } from 'node:fs';
import { createPetBehavior } from './tools/creatures/viewer/behavior.mjs';
for (const id of ['astral_seer', 'pocket_magnet']) {
  const load = file => JSON.parse(readFileSync('tools/creatures/viewer/atlases/' + id + '/' + file));
  const { animations } = load('atlas.json');
  const config = load('behavior.json');
  function run(seed) {
    const pet = createPetBehavior(config, animations, seed);
    return Array.from({ length: 1440 }, () => {
      const { anim, at, frame } = pet.sample();
      pet.advance(1 / 24);
      return JSON.stringify([anim, at, frame]);
    });
  }
  function different(a, b) {
    return a.filter((value, i) => value !== b[i]).length;
  }
  const a = run(config.seed);
  console.log(id, Object.keys(animations).length, animations.trick.frames, animations.trick_b.frames,
    different(a, run(config.seed)), different(a, run(config.seed + 1)), different(a.slice(0,720), a.slice(720)));
}
JS
```

Замер совместим с наблюдением Claude о повторяющемся порядке занятий в 20 из 36 карточек. В Б26 считались записи сценария в карточках. Здесь сравнивалось покадровое состояние проигрывателя. Один и тот же порядок занятий допускает отличия в позиции или фазе. [Б26, корпус и порядок занятий](../b26/boredom.md) · [Проигрыватель](../../../tools/creatures/viewer/behavior.mjs#L585)

**Условие пересмотра ранга.** Если в слепой паре зритель одинаково объясняет события с памятью и без неё, первый приоритет не подтверждён. Если причину света в неподвижной миниатюре узнают и без пересчёта материалов, В3 следует сравнить её стоимость с заранее нарисованными вариантами. Из этих сравнений нельзя вывести выбор поколения за владельца.
