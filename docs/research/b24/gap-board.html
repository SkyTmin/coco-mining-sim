Астрал, Полюсик и внешний пример

В каждой строке три поля по 224 × 192 CSS-пикселя. Кадр целиком вписан в поле с сохранением пропорций. Нажатие открывает исходник. На узком экране прокрутите строку вправо.

Для первых двух столбцов нужны PNG из комплектного рендера рядом с HTML. Правый столбец загружает оригинальные кадры витрин по сети. Разрешение оригинала, величина героя и частота движения у примеров различаются.
