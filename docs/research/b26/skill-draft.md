## 12. Замысел картины — до первой позы

### 12.1. Порядок

1. Цель владельца одной строкой: **свойство, а не предмет** (`intent.md` §1).
2. Сверка с вкусом владельца (`owner-taste.md`).
3. Ответы на 9 вопросов логики — в карточку (поля ниже). Нет ответа — нет замысла.
4. Форма картины из каталога (`forms.md`); у двух картин подряд — разные; секретные — нестандартная форма или
   смесь, которой ещё не было; у обычных — тоже своя.
5. Расписание жизни из трёх слоёв: рутина → события → редкость (`boredom.md` §3).
6. Кадр-обложка — существо в своей среде, как иллюстрация карточки (`cards.md`).
7. 2–3 варианта замысла картинкой и строкой → выбор владельца → производство без вопросов.

### 12.2. Новые поля карточки (`card.json`) — предложение для Б23 Ф4

```json
"concept": {
  "goal": "цель владельца одной строкой",
  "who": "кто он и чего хочет",
  "unique": "что умеет только он и почему (из тела)",
  "magic": [{ "rule": "…", "cost": "чего стоит", "limit": "чего не может", "shownAt": "где зритель узнаёт правило" }],
  "constants": ["размер героя", "что чем является", "масштаб планов"],
  "mechanism": "один главный механизм картины",
  "form": "номер и имя формы из forms.md",
  "schedule": { "routine": ["…"], "events": ["…"], "rare": ["…"] },
  "cover": "кадр-обложка: момент и композиция",
  "cardAbility": "умение будущей карточки словами (без чисел)"
},
"moves": [{ "...": "как сейчас", "cause": "что запускает", "effect": "что делает", "aftermath": "что остаётся в мире" }]
```

### 12.3. Проверка замысла (до кода)

- Человек, не читавший карточку, пересказывает каждый трюк одной фразой — совпадает с `cause → effect → aftermath`.
- Ни одна константа не меняется без события на глазах.
- У магии есть цена и предел, и правило видно раньше, чем им пользуются.
- Трюков столько, сколько вытекает из `who` и `unique`; ни одного «чтобы были».
- Главное действие — в центре внимания и в полный рост.

### 12.4. Нельзя

- Шаблон `idle walk look walk fidget walk idle` по умолчанию (20 из 36 картин на 28.11).
- Набор механизмов вместо одного (Хранитель дверей, первая версия: 1/5).
- Буквальное прочтение слов владельца.
