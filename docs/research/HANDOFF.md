## С чего начать в новой сессии

1. Открыть рабочую ветку [chatgpt/b25-research](https://github.com/SkyTmin/coco-mining-sim/tree/chatgpt/b25-research). Проверить `AGENTS.md`, [порядок Б25](../tz/TZ-B25-paket-codex.md), [актуальные решения](DECISIONS.md), затем решения по [свежей ветке Claude](https://github.com/SkyTmin/coco-mining-sim/blob/claude/vibrant-darwin-yyjj48/docs/research/DECISIONS.md). Учесть новые коммиты перед любым шагом, зависящим от решения. Исследование работает в этой рабочей ветке.
2. Начать с [таблицы результатов Ф3 в проекте](b23/design.md). Для каждого числа перейти к отчёту и `results/`. Код опытов находится в [отдельной ветке — зафиксированная ревизия b2ff612](https://github.com/SkyTmin/coco-mining-sim/tree/b2ff6123576c7c14b97ff30534f3c31f1ceddc8b/docs/research/b23/experiments). Скопировать программы в локальный отдельный checkout. Рабочий каталог для программы и нужная ревизия входов указаны в отчёте соответствующего опыта.
3. Без записи о приёмке Ф4 продолжать сверки и измерения. При замечаниях Claude поправить конкретный пункт проекта и его условие отказа, воспроизвести связанный опыт, получить новую независимую подпись и обновить эту передачу. После явной приёмки начать с нулевого шага Ф5 в [проекте](b23/design.md) и зафиксировать действующую ревизию всей мастерской. В случае новых принятых картин заново построить матрицу ID. В решении 0a6aa41 два вопроса переданы проекту Ф4 для выбора значений по умолчанию. После каждого изменения — полные проверки, контроль восьмёрки, журнал потерь и откат при регрессии.

## Как воспроизвести и что ещё открыто

**Версии.** Для исходной восьмёрки использовать всю ревизию `d6ebb31`. Новый Полюсик измерен отдельно на `cced294`: gate 0 ошибок и 0 предупреждений, 4 083/4 083 кадра, 26,74 с, 640,7 МиБ в принятом методе измерения. Его новая галерейная упаковка принята в `2b1b9cd`. Правило отказа и художественной планки — `957f878c`. [Разница кадров](b23/pocket-revision.md) · [Первичная база решений](DECISIONS.md)

**Команда замера.** На Linux подготовить отдельный checkout нужного коммита и поставить зависимости его `tools/creatures` через `npm ci` только в исследовательской среде. Из `tools/creatures` выполнить `python /путь/к/measurements/measure.py --output /tmp/b23-new-run --operations render-idle gate snap`. Длительные команды работают с одним worker. Вывод по операции сохраняется отдельно, готовые одноимённые файлы в каталоге вывода позволяют возобновить серию. Не смешивать файлы разных условий и ревизий в один каталог. Номер CPU выбирается для свободного процессора окружения; исходный Ф0 закреплял CPU2. В Ф3 версия Node указана в каждом исследовании: геометрические и браузерные выводы, хеши и бюджеты нельзя переносить между средами без повторения. [Протокол и другие команды](b23/baseline.md) · [Измеритель](b23/measurements/measure.py)

**Точное незавершённое место.** Локальные холодные `snap` для исходной восьмёрки выполняются последовательно. На момент этой передачи подтверждены Астрал, исходный Полюсик, Зенит (10 828/10 828 за 1 674,44 с), Огонёк (4 626/4 626) и Пончик (10 852/10 852 за 822,05 с). Идёт Титан, далее Краб и Мурлен. При возобновлении взять отсутствующие ID по строкам `b23/measurements/samples.jsonl`, затем сохранить два повтора idle и таблицу разброса. Титул приёмки Б22 с полной сверкой 41 не подменяет этот разрез по времени и RSS. Профиль восьмёрки уже передан. По новому замечанию владельца отдельный read-only замер вычисляет отклонение длины жёстких костей от позы покоя на 41 работе. Следующая запись — сводка измеримых и непокрытых ригов, список срабатываний с кадрами и скептической перепроверкой в [таблице длин](b23/bone-length.md). Параллельное воспроизведение на хостах Linux, macOS и Windows сравнивает по 287 авторских фаз одного среза. [Протокол](b23/measurements/platform/protocol.md).

**Условия проверки.** Значения по умолчанию для телефона и времени жизни мира даны в [проекте Ф4](b23/design.md). Натурный замер устройства предстоит; числовой бюджет проверяется парным запуском. Точный расход токенов этой сессии и Полюсика не зафиксирован. Автоматическая подсказка масштаба, расхода и плотности движения не предсказывает оценку владельца.

**Приоритеты Ф3 от Claude.** [Опыт 03](b23/experiments/03-coverage/report.md) завершён. По [кости](b23/bone-length.md) подписана промежуточная геометрическая сверка 41 × 3 позы, 33 измеримые работы и 456 сопоставлений. Следующий шаг — доставить полную таблицу и отдельный браузерный F1. Для голубя Мурлена на двух веб-входах воспроизведено исчезновение светлой области 3→84→244→0 пикселей. Довести опыт 08 до проверки намеренных уходов и передать независимому скептику. Два [значения по умолчанию в проекте](b23/pilot-defaults.md): физический Galaxy A16 5G с 4 ГБ, мир сохраняется в профиле после закрытия до явного сброса или удаления данных.
