# Полюсик после переноса эффектов Б22

Владелец одобрил перенос эффектов, Claude обновил принятую картину и её эталон в `cced294`. Сравнение ниже относится к одному `pocket_magnet`. Строка Полюсика и первичное чтение листа B в эталонной восьмёрке Ф0 относятся к прежней версии `d6ebb31`. Исходный и новый каталоги `tools/creatures` содержатся в независимых checkout. [Решение владельца](https://github.com/SkyTmin/coco-mining-sim/blob/cced294da2ebed3a0db5a5f9e6100903a849a739/docs/research/DECISIONS.md) · [Изменение автовремени и регистрации контактов](https://github.com/SkyTmin/coco-mining-sim/blob/cced294da2ebed3a0db5a5f9e6100903a849a739/tools/creatures/c/pocket_magnet.ts#L18) · [События 44, 131 и 111](https://github.com/SkyTmin/coco-mining-sim/blob/cced294da2ebed3a0db5a5f9e6100903a849a739/tools/creatures/c/pocket_magnet_fx-beats.ts#L7)

Один пиксель считали изменённым, если различался хотя бы один канал RGBA. Размер кадра 176×144, 24 кадра/с, normal, направление 0. У рыбки первая разница видна на такте 44 (187 пикселей), у звезды на такте 111 (313 пикселей). Время отображения при поимке изменилось. Показатели после 111 включают сдвинутую фазу движения и дрожание камеры. Два последних кадра новой версии звезды не имеют пары с таким же индексом в прежней. Полный покадровый ряд, SHA и номера кадров иллюстраций сохранены. [Измерение](measurements/pocket-delta.json) · [Скрипт сравнения](measurements/compare-pocket-revisions.mjs)

| Что известно | Как это трактуем | Уверенность и граница |
| --- | --- | --- |

| Первая разница у двух трюков приходится на зарегистрированный индекс контакта. | Выбор кадров должен захватывать обе стороны этого места. | Высокая для индекса и подсчёта пикселей. Зрительскую заметность отдельно оценивают по показу на ×1. |
| В DECISIONS записана реакция владельца на прежний пример FX. | В отчётах о восьмёрке и в следующих опытах следует явно указывать версию Полюсика. | Высокая для записи решения. Количество разнящихся пикселей не предсказывает художественную оценку владельца. |

## Один процесс на каждом замере

| Команда | Исходный d6ebb31 | Принятый cced294 |
| --- | --- | --- |
| `render-idle` | 4.48 с / 243.2 МиБ | в очереди |
| `gate` | 21.30 с / 944.6 МиБ, 0 ошибок / 0 предупреждений | в очереди |
| `snap` | в очереди | в очереди |

Условия и ограничения описаны в основном Ф0. Время выводится для одного прогона, без заключения о выигрыше производительности. Путь `BASE` задаёт `tools/creatures` исходного checkout, `REVISED` — принятого. Для Node нужен `tsx` и штатные зависимости из lock-файла в каждом из каталогов. Только чтение эталонов. [Базовая серия](baseline.md)

```sh
node --import tsx ../../docs/research/b23/measurements/compare-pocket-revisions.mjs "$BASE" "$REVISED" /tmp/b25-pocket-delta
cd "$REVISED"
taskset -c 2 python /path/to/measure.py --output /tmp/b25-pocket-updated --ids pocket_magnet --operations render-idle gate snap
```
