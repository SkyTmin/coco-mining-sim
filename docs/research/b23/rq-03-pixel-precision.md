## Что осталось неизвестным и где остановились

Девять запросов охватили оригинальные названия фильтров, русло публикаций о временной согласованности, художника и настройки движков; один запрос включал японские термины. Исторический RotSprite сверяли по живой реализации Aseprite и по сравнению в MMPX. Запуск оригинального бинарника Xenowhirl здесь не проверяли. Установить единый порог «контур закипел» для всех допустимых движений по этим материалам не удалось. Масштабирование для неподвижной картинки само по себе такое утверждение не подтверждает.

Вопрос насыщения — появился ли новый этап, на котором исправлять дефект, или новый способ оценить его при данном выборе. После алгоритмов преобразования растра, временного контроля отдельных линий, художественного субпиксельного движения и привязки сетки вывода просмотрели три независимые первичные спецификации/описания подряд: WHATWG Canvas, PixiJS, Phaser. Все три подтверждают уже учтённый режим выборки готовой текстуры; новых этапов для исправления геометрии и её временной проверки в этих разделах не появилось. У различий API собственное значение для конкретных движков.
