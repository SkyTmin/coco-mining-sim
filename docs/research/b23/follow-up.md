**Результат для метрики.** Одна подтверждённая временная несогласованность на восьми работах по одному клипу, плюс два наблюдения о кадрировании; один заподозренный выход за край оказался предусмотрен постановкой. Источником для F был штатный автомат галереи при double_tap из начального состояния и CPU-композиция следующей позы. Захват экрана настоящего телефона этим числом не обозначен. Общий класс исчезающих реквизитных элементов уже известен из уроков; конкретная причина и конец фирменного клипа проверены здесь. До явной художественной приёмки ориентиром остаются принятые работы, а не число предупреждений.

**Проверка в штатной галерее.** Позже повторено в Chromium 156 при мобильных параметрах 390 × 844, DPR 2, без GPU. По обычной глубокой ссылке `?pet=moon_magician` выполнены два настоящих touch-события. В нативном canvas галереи 292 × 244 при trick 129, 130, 131 и следующем показанном turn были соответственно 3, 84, 244 и 0 ярких пикселей в том же окне. Ошибок страницы и HTTP отказов не зарегистрировано. Независимый запуск с клавишей 2 дал те же четыре числа. Переход наблюдался в браузере на компьютере с мобильной эмуляцией.
