# Ф0 · исходный набор мастерской

В наборе Астрал, Полюсик, Зенит, Огонёк, Пончик и три прежних отказа: у Титана перекрывалась голова, у Краба отсутствовала регистрация листа, у Мурлена кисть заходила в шляпу. Исходный корпус для регрессии содержит 41 картину с golden, включая исходного Полюсика. В Б22 действует отдельный режим предупреждений для остальных 40. Эксперимент pocket_magnet_fx имеет собственный gate, отсутствует в корпусе 41 golden и в этой восьмёрке. ## Труд агента и слепой просмотр

По истории исходного Полюсика документированы пять генераций рисунков, правки обоих трюков, независимый просмотр и два коммита 73bc9e6 и c792904. В частности, у звезды исправлены пересечение хвоста с головой на кадрах 84–103 и скольжение ступни на 60. Это нижняя граница в один цикл исправления. Исторический .studio/ws-log.jsonl не отслеживается в Git. Его схема хранит команды, секунды, RSS и байты stdout. Полное число действий автора, точные токены и полное число кругов до приёмки пока неизвестны. Текущие команды сверки Б25 не следует приписывать автору. [Полюсик в PROGRESS](../../PROGRESS.md) · [Схема ws-log](../../../tools/creatures/studio/ws.ts) · [Пять промптов](../../reports/creatures/pocket-magnet/README.md)

## Повторение

Из tools/creatures с зависимостями из npm ci. Для первого прохода использована команда ниже. Новый номер повторения сохраняет новый результат. Медианы для сравнения изменений в Ф3/Ф5 требуют дополнительных запусков в тех же условиях. Проба полного экспорта доступна через --operations render-all.

```sh
taskset -c 2 python ../../docs/research/b23/measurements/measure.py --output /tmp/b25-f0 --operations render-idle gate snap
node --import tsx ../../docs/research/b23/measurements/shared-lines.mjs
python ../../docs/research/b23/measurements/source_inventory.py
```
