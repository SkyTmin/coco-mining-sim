## Строки кода и повторное использование

В левом столбце все отслеживаемые файлы c/<id>.ts и c/<id>-*.ts. В двух следующих столбцах перечислены строки TypeScript в файлах, достижимых по статическим импортам esbuild из модуля героя, life, сцены, рамы и композитора. Общими считаются файлы, достижимые минимум для двух из 41 картин. Код npm, vendor, JSON-данные, типовые импорты, удалённые компилятором, и динамически выбранные файлы вне этих точек входа исключены.
