# Ф0б. Когда в мастерской 100 и 300 картин

Уже на виртуальной стене из 300 записей штатный просмотрщик создал 300 холстов, хотя зритель видел только верх страницы. При самостоятельных адресах постеров и атласов для каждой записи размер одного листа достиг 2048×8880, его несжатая RGBA и логические поверхности стены составили вместе 130,39 МиБ. Реальный пик памяти телефона пока неизвестен. В выборке принятых картин исключение фона из поиска похожих работ сменило первую пару. В 24 новых заготовках ни одна из трёх проверенных поз не упёрлась телом в край кадра. [Измерения галереи](measurements/scale/gallery-scale.json) · [Ранжирование](measurements/scale/diversity.json) · [Заготовки](measurements/scale/combos.json)

## Данные и единицы

41 ID — пересечение каталога из 74 записей и 41 файла golden. Включён нативный `rat_king`, у которого отсутствует индивидуальный atlas.json. В моделях на 100 и 300 многократно повторён исходный порядок каталога, а последнему проходу взято нужное начало. На диске принятые работы, gallery, golden и исходники не менялись. Срез размера tracked — дерево Git `d6ebb3145d47d6bed85b088ec30b0b2faa82da6f`, 471 963 277 байт содержимого blob по путям. Объекты .git и история в эту величину не входят. Размер МБ десятичный, МиБ = 2²⁰ байт. [Инвентарь и состав каждой картины](measurements/scale/scale-inventory.json)

При том же составе 300 отдельных работ дали бы около 1 364 МБ одной этой части поставки. Если в дереве Git менять только отдельные атласы, golden и файлы c/, добавление их модельной дельты к текущим 471,96 МБ даёт около 732,7 МБ при 100 и 1 642,3 МБ при 300. Это сумма содержимого tracked-файлов, без дедупликации Git, будущих доказательств и расширения постеров. Состав влияет сильнее среднего: `eclipse_drake` уже занимает 33 862 986 байт в 44 файлах индивидуальных атласов. [Расчёт по ID](measurements/scale/scale-inventory.py)

GitHub указывает максимальный размер опубликованного сайта Pages 1 GB, мягкий лимит 100 GB трафика в месяц и 10 минут на развёртывание. При названной модели поставка 300 превысит лимит сайта уже одними индивидуальными атласами. У одного GitHub Release максимум 1 000 assets, каждый меньше 2 GiB: 2 699 самостоятельных файлов не поместились бы в один релиз при схеме «файл = asset». Число 511 в истории — отдельное ограничение предыдущей системы Artifact, оно прямо записано в её упаковщике. Реальной публикации и замера CDN не проводили. ## Что испытал браузер

Холодный контекст для каждого случая. Chromium 156, headless, Linux x64, CPU 3, GPU отключён, экран 390×844 CSS-пикселя, DPR 2, сенсорный ввод. Запущены неизменённые модули viewer через временный локальный HTTP-сервер. У каждого ID отдельная карточка. В «общих» копии ссылаются на исходные атласы и прямоугольники. В «отдельных» у каждой копии собственный URL/прямоугольник при тех же исходных рисунках. Лист упакован строками шириной 2048 и закодирован Pillow WebP quality 88, поэтому даже случай 41 — контролируемый каталог только из принятых работ, с экспериментальной упаковкой. Сетевые байты — длины тел ответов, успевших попасть в журнал к готовности всех настенных холстов, без заголовков, TLS и кеша CDN. Измерен один запуск под общей загрузкой машины. **Предложение для опыта.** Разбить постеры по страницам, создавать холст в окне видимости и снимать невидимые поверхности по бюджету. Первая проверка — те же 300 разных ID, 3 переключения до и после готовности, фактические `img.decode()` и число холстов при прокрутке вверх-вниз, затем физический слабый телефон. ## Разнообразие, пары и отрицательные результаты

287 полных RGBA-кадров на Node 22.14.0 совпали с SHA-1-префиксом golden. Для каждой работы взяли фазы idle 0, ¼, ½, ¾ и walk 0, ⅓, ⅔, округляя индекс вниз. Признаки рассчитали по слоям от того же вызова compose: силуэт idle в окне 40×40, расстояние Жаккара по альфе ≥128; 64 корзины RGB тела и расстояние Хеллингера; средняя абсолютная разность семи относительных изменений маски между выбранными фазами, после выравнивания на опору `feet`; фон 8×8 RGB и среднее абсолютное различие. В каждой из четырёх колонок ранжировали все 820 пар с усреднением связок, затем взяли среднее рангов. 0,07 означает близость по выборочной шкале, а не 93% художественного сходства. Освещение, FX, жест из tech-клипа и смену такта внутри другого эпизода эта выборка пропускает. ## Повторить

Из корня checkout; временная директория должна быть доступна на запись, нужен Node 22.14.0 в PATH, окружение проекта, Python с Pillow, numpy и Playwright, исполняемый Chromium. Для сравнения второй Node передаётся явным путём. Для одного процесса именно версии Node обязательно передавать соответствующий бинарник, так как дочерние запуски используют process.execPath.

```sh
D="$(pwd)/docs/research/b23/measurements/scale"
T="$(mktemp -d)"
python "$D/scale-inventory.py" > "$T/inventory.json"
taskset -c 3 python "$D/scale-gallery.py" "$T/gallery"
(cd tools/creatures && taskset -c 3 node --import tsx "$D/sample-diversity.mjs" "$T/frames22")
taskset -c 3 python "$D/diversity.py" "$T/frames22" "$T/closest.png" > "$T/diversity.json"
taskset -c 3 python "$D/diversity-inputs.py" > "$T/combos.json"
(cd tools/creatures && B25_RECORD_MISMATCH=1 taskset -c 3 "$NODE24_BIN" --import tsx "$D/sample-diversity.mjs" "$T/frames24")
python "$D/version-diff.py" "$T/frames22" "$T/frames24"
```

Предсмертные гипотезы об объёме листа, неполном учёте RGBA, одинаковости, чувствительности оценки к фону, CI и тяжёлом хвосте получили фактические данные (1, 7–9, 11, 14). Для 2 проверены только завершённые переключения; для 3 — байты готовой стены. 4–6 (работа за экраном, инвалидация, смешение версий) требуют отдельной телеметрии. Для 10, 12, 13 лабораторные проверки переноса/вариантов/повтора опубликованы в В3, реальная игра и телефон остаются открытыми. [Технологии В3](../b24/tech.md)
