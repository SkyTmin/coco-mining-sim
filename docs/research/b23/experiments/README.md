# Ф3 · проверенные опыты

Исполняемый код сохранён в [отдельной ветке опытов](https://github.com/SkyTmin/coco-mining-sim/tree/chatgpt/b25-experiments/docs/research/b23/experiments). В этой рабочей ветке лежат условия, результаты и ссылки. На обычном запуске старой мастерской файлы опыта не подключаются. Приведённые в статьях команды запускаются из исходного checkout соответствующей ревизии; каталог с кодом опыта можно указывать абсолютным путём. Новое художественное содержание Б24 поручено Claude. [Правило владельца](../../DECISIONS.md)

| Что проверили | Вывод для проекта Ф4 |
| --- | --- |
| [01. Правило магии и расход заряда](01-state-price/report.md) | В технической модели расход сохранился при смене клипа, исходный растр остался прежним. Пилоту нужны именованное событие, версия правила и видимый слой. |
| [02. Что видит Claude на родном масштабе](02-native-eyes/report.md) | Авторские и равномерные девятки пропустили разные заранее внесённые однокадровые подмены. На 96-м кадре Астрала все 430 изменившихся пикселей лежат вне окна у тела. Показывать полный кадр и примыкающие фазы. |
| [03. Действительное число проверенных кадров](03-coverage/report.md) | Проверять ожидаемые имена и число кадров для каждой работы до вызова рендера; общий итог способен скрыть потерянный ID. |
| [04. Непрерывная геометрия контакта](04-contact/report.md) | На синтетике непрерывная проверка нашла 600/600 пересечений против 280/600 у прежней. Все 15 исторических меток сохранились. Намеренные перекрытия требуют авторского исключения. |
| [05. Поверхности обложек у видимой области](05-poster-window/report.md) | На 300 записях и экране 390×844 ограниченное окно удерживало до 16 поверхностей. Проверены байты 223 видимых изображений во всех размерах стенда. На 41 записи выросло количество повторных рисований. |
| [06. Плоскость сгиба конечности](06-ik/report.md) | Длина восстановлена в 128 специальных позах, однако скачок колена вырос с 3,46 до 4,90. Универсальная замена отклонена. |
| [07. Рисунок технического следа в браузере](07-browser-state/report.md) | Испытательная страница проверяет отдельно состояние и наблюдаемые пиксели расхода и следа на настоящем атласе. Художественная заметность остаётся для зрителя. |

В протоколах отдельно записаны область применения на восьми картинах, контролируемые неудачи и пределы переноса. У каждого опубликованного отчёта есть проверка версии по SHA-256. [Рецензии](../peer-review.jsonl) · [Ф0](../baseline.md) · [Ф2](../checkpoint-1.md)
