# Проверка границы восстановления состояния
До запуска. Две страницы Chromium одного origin читают из localStorage один допустимый сохранённый мир опыта 01 с единицей заряда. В каждой — отдельный экземпляр события одной картины, по одному обработчику. При навязанном порядке «обе прочли, обе вычислили, обе записали» ожидаю два статуса applied для одного заряда, в итоговом сохранении только одна запись. Обратный порядок записи должен изменить её идентификатор. Отрицательный контроль — второй обработчик читает состояние только после первой записи. Тогда ожидается один applied и один insufficient. Двенадцать пар с чередованием порядка; проверяется возможность заданного чередования в Chromium. Частота совпадений в реальной галерее, нормативные свойства Web Storage и устройство будущего хранения этим опытом не оцениваются.
