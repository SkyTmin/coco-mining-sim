# Ф0б. Поиск однокадровых возвратов по всем эталонам

На срезе d6ebb31 перебраны все 164 971 кадровых отпечатка из 41 эталона. В 1 139 клипах есть 162 693 внутренних тройки последовательных кадров. Критерий был один: крайние изображения имеют один и тот же отпечаток, среднее — другой. Это проверяемый способ найти короткий всплеск. Для каждого совпадения заново отрисованы все три опорные фазы и проверены оригинальные RGBA. [Скрипт скрининга](screen.py) · [Программа попиксельной проверки](confirm.mjs)

Обнаружены 63 вхождения в 22 клипах шести работ. Во всех 63 случаях отпечатки совпали с эталоном, крайние изображения оказались побайтно тождественными. На среднем менялось от 4 до 354 пикселей. Если сгруппировать одинаковые пары отпечатков «крайний/средний» с учётом размеров, остаются 27 групп. Например, состояние лапы у lunar_plush на fidget_b/16 повторилось в life/1085 и showreel/206. Без проверки повторов число 63 плохо подходит для подсчёта разных проблем художника. [Все 41 работы и 63 попадания](screen.json) · [Размеры, координаты и проверка совпадения](confirm.json)

Решение о браке не присваивалось. Граница между клипами не входила в тройки: подтверждённый обрыв голубя у Мурлена на переходе trick→turn этот критерий пропустил. Плавная последовательность трёх разных изображений и скачок, после которого композиция продолжает движение, тоже проходят мимо. Для Ф4 существеннее показывать локализованную разницу сразу в контексте трёх кадров и группировать повторы в составных клипах. [Свидетельство перехода у Мурлена](../red-mobile/observations.md) · [Построение трёх листов для просмотра](see.mjs)

Скрининг всех кадров автоматический, глазами разобраны три последовательности в двух масштабах. В [мобильной галерее](../red-mobile/observations.md) отдельно просмотрено по одному кадру всех 41 работ. Воспроизводить из tools/creatures фиксированного среза с его зависимостями. Каталог скриптов задать в D, временный каталог для результатов — в T.

```sh
python "$D/screen.py" "$T/screen.json"
node --import tsx "$D/confirm.mjs" "$T/screen.json" "$T/confirm.json"
node --import tsx "$D/see.mjs" "$T/views"
```
