# Однокадровые возвраты в шести работах

В эталонном корпусе из 41 картины найдено 63 случая, когда два одинаковых кадра окружают единственный отличающийся. У многих эпизодов есть копии в составных клипах. В этом просмотре разобраны все 27 различных пар изображений, на которые распались 63 случая. Для каждой пары заново получены три исходных кадра. Верхний ряд листа показывает всю картину в родной сетке, нижний — участок всех отличающихся пикселей и два пикселя полей при увеличении ×4. Отпечатки трёх кадров проверены до сохранения листа. Равенство полных пикселей объединяет точные повторы и оставляет близкие случаи раздельно. |

Этот просмотр охватил 81 изображение в 27 тройках, выбранных одним условием. По ним я не нашёл основания присвоить этим шести картинам новый художественный брак. Переходы между клипами и случаи с разными соседями остаются за пределами отбора. Например, проверка по этому условию пропускает исчезновение голубя при смене клипа Мурлена. Вердикт владельца о рисунке и частота заметных сбоев на других кадрах здесь не измерялись. [Подтверждённый переход](../red-mobile/observations.md)
