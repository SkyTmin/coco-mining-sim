# RQ02. Скелет, порядок частей и рисование тела в пиксели

У каркаса, деформации поверхности и окончательного перекрытия разные задачи. У Spine и DragonBones порядок слотов имеет собственную дорожку. В Godot вершины Polygon2D получают веса относительно позы покоя. Live2D может связывать вершины двух отдельных сеток, а Rive деформирует рисунок вложенного компонента. По этим источникам нельзя выбрать один риг сразу для сферического малыша, многозвенного змея и крыла. ## Два отрицательных контроля

На паре перекрывающихся прямоугольников перестановка переднего слоя сохранила все 24 пикселя маски, но в восьми точках поменяла видимый цвет. Из равенства силуэтов нельзя вывести одинаковый порядок деталей. Во втором опыте два противоположных вращения единичного вектора дают длины 1 и 1, а среднее с одинаковыми весами — длину 0. Это крайний арифметический случай линейного смешивания. На частично сгибающемся реальном крыле нужна отдельная проверка величины потерь. Маркеры выполнены без чужой графики, стандартной библиотекой Python.

## Что сравнить в Ф3

Для порядка попеременно вывести лапу позади и перед мордой, сохранив внешний силуэт. Снять время правки и число авторских параметров для трёх вариантов. Это план сравнения, данных о скорости или предпочтении зрителя в Б25 ещё нет. Наименее дорогая проверка использует текущие примитивы и метки. Импорт лицензированного проприетарного рантайма не входит в план.

## Воспроизведение опыта

Из каталога с временным файлом сохранить приведённый код как `probe.py` и выполнить `python probe.py`. Достаточно стандартной библиотеки Python.

```python
from math import hypot
left = {(x, y) for x in range(4) for y in range(4)}
right = {(x, y) for x in range(2, 6) for y in range(4)}
def composite(first, second):
    pixels = dict.fromkeys(first[0], first[1])
    pixels.update(dict.fromkeys(second[0], second[1]))
    return pixels
front = composite((left, 'red'), (right, 'blue'))
back = composite((right, 'blue'), (left, 'red'))
print('silhouette pixels', len(set(front) | set(back)))
print('silhouette difference', len(set(front) ^ set(back)))
print('changed visible colour', sum(front[p] != back[p] for p in front))
# A bind-space unit vector rotated around the same root by +90 and -90 degrees.
a, b = (0.0, 1.0), (0.0, -1.0)
v = tuple((x+y)/2 for x,y in zip(a, b))
print('single influence lengths', hypot(*a), hypot(*b))
print('blended length', hypot(*v))
```
