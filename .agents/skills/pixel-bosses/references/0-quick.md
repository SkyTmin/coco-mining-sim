## 0. Быстрый путь партии

**Планка** — принятый третий пилот (4,5–4,8 из 5): `docs/reports/creatures/pilot-3/` (`paintings.gif`,
`<id>/painting-showreel.gif`). Новое существо не хуже ни по одному пункту.

**Инструмент** — `tools/creatures`, `npm run ws` (`studio/README.md`):
- `probe <id> <anim> <кадр>` — числа кадра; правь позы по ним, картинку смотри потом;
- `sheet <id> <anim>` — один лист кадров вместо GIF; `--against <ref>` — только изменения;
- `check <id> <приём>` — автокритик одного приёма за 3–5 с: это цикл правки, полный `gate` — перед критиком;
- `gate <id>` — автокритик + подробности + числа приёмов; **зелёный `gate` — условие, чтобы звать критика**;
  `gate all` — параллельно, неизменённые зелёные существа пропускает;
- `snap <id> --check` — какие кадры изменились против эталона `golden/<id>.json`; после приёмки — `snap <id>`;
- `render <id>` — кэш и параллель.

**Порядок на существо**
1. Карточка данными: тип тела, пропорции, части, материалы (5–7 тонов, фактура), список подробностей (≥ 25 / 35 / 50
   по редкости, §4.0б), приёмы — шаблон + параметры + цепочка «кто чем по чему, откуда сила, точка контакта, что
   происходит, возврат» (§4.3б), язык эффектов, сценарий `life` (§8.7). Критик принимает карточку.
2. Заготовка из типа тела и шаблонов приёмов (когда библиотека готова — `ws new`). `rig.tag` на каждой части.
3. **Референс каждого приёма** (§4.3в): аналог из жизни и его фазы в карточке → 2–3 подсмотренных примера (игры,
   мультфильмы, видео — как пример, ссылки в карточку; пишем и рисуем сами) → свой лист ключевых поз (картинка,
   фон `#FF00FF`) → владельцу вместе с контрольной точкой (шаг 4). Шаблон из библиотеки тоже сверяется с листом.
4. **Контрольная точка партии**: форма в `idle` + листы референсов + ключи одного приёма у каждого существа — один общий лист владельцу,
   работа не ждёт ответа. Остановил — правишь сейчас, а не после отделки.
5. Форма и позы → проход подробностей → приёмы (ключи — по листу референса, сверка `ws ref`; ключи принимаются листом `sheet` до промежуточных кадров; ключ —
   целями решателя тела: `reach`/`aim`, углы руками только для характера) → фон и рама, если тема или редкость новая.
6. `gate <id>` без ошибок. Предупреждения — либо исправить, либо правило в `c/<id>.studio.json` с причиной.
7. Критик: `sheet` и `ws ref` каждого приёма, `life`, общий `paintings.gif`; оценки 1–5 с номерами кадров (§7.2). Второй
   круг — `sheet --against`.
8. Отчёт: таблица из `gate` + короткие заметки; владельцу — сводка, `paintings.gif`, `showreel` каждого. Принятое
   владельцем — `snap <id>`, эталон в git.
