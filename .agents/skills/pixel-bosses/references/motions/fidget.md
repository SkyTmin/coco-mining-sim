# Два разных жеста

**Фазы при 24 кадрах/с.** 0 покой, 10–14 выбор объекта, 26–30 вершина жеста, 47 возврат. Второй жест имеет собственные цель и вершину.

Взгляд первым находит цель. Вытяжение шеи помогает принюхаться; при кормлении клюв замыкается только у травы. Предмет остаётся в той же кисти.

- Двуногий. Наклонить корпус над опорной стопой и дать второй конечности свободу.
- Четвероногий. Опереть грудь на передние лапы, повернуть или опустить шею в просвет между ними.
- Летун. Подобрать одно крыло на насесте, провести клювом по перьям, затем сложить крыло.
