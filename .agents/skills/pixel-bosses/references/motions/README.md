# Библиотека движений

Для выбранного клипа открой соответствующую строку. Тайминг дан при 24 кадрах/с.

- [idle.md](idle.md) — дыхание, перенос веса и моргание.
- [fidget.md](fidget.md) — два коротких жеста со своей целью.
- [look.md](look.md) — взгляд, поворот головы и возврат.
- [happy.md](happy.md) — сжатие и мягкая посадка, ритм хлопков ластами.
- [trick.md](trick.md) — подхват и ловля реквизита, равновесие на одной лапе и поклон.
- [sleep.md](sleep.md) — засыпание, шов дыхательной петли и пробуждение.
- [wake_startled.md](wake_startled.md) — испуг и переход к радости.
- [hatch.md](hatch.md) — освобождение из оболочки и первый жест.
- [gait.md](gait.md) — опора стопы, походка по параметрам типа тела и разворот.
- [slide.md](slide.md) — салют, разбег, скольжение и торможение, пример вертикальной посадки.
